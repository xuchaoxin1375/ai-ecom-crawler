## 验收原则

**先看用户结果和具体错误，再选择足够的验证。** 合成样例验证数据处理，固定真实样本核对语义，真实灰度验证访问和动态执行，完整目标检验运行及结果；这几类证据不能互相冒充。

本文档给出验收设计和[合成示例](示例/README.md)，不包含已跑过的采集用例或真实网页Fixture(固定验证样本)。实际用例由各实现团队建设，期望来自独立核对的页面／公开数据和本文档规则，不能直接拿实现输出充当期望。

## 必须覆盖的场景

| 场景 | 输入／触发 | 预期业务结果与证据 |
| --- | --- | --- |
| A01 正价／零价／无价 | 29.00、0、负数、空及非法金额 | 只有有限正价进入有效集，其他分别留因；不填零、不偷偷丢原网址 |
| A02 变体最低价与选项 | 缺货S码29、在售M码35，Size和Color可选 | 取29、完整公开选项、库存附带；无全部组合报价采集 |
| A03 税价与市场 | 同币种未税24.17／含税29；另有其他市场报价 | 通常取24.17并标未税；其他市场不能混取，特殊任务例外明确 |
| A04 完整正文与摘要 | 短摘要、完整说明、参数表共存 | 保留清洗正文和参数，不只取摘要；产品正文不因关键词被误删 |
| A05 复杂部分描述 | 一区正常，另一复杂关联区无法可靠加载 | 有界尝试后可交部分，标缺失区块和限制；预览／任务报告／异常索引均可辨 |
| A06 HTML与裸文本 | JSON中含HTML、另一原生文本含Unicode与换行 | 前者清洗HTML，后者真实文本；不重复解码或人为丢结构 |
| A07 主图／分类／品牌／单位 | 旁边有Logo、推荐图、无品牌、明确销售单位 | 主商品图、原站有意义类别、无品牌留空、单位只在需要时补且不重复 |
| A08 从入口自主构建 | 未知普通HTML、足够工具及代表样本 | 尽早规划发现和获取，真实试跑修订，完整方案和失败反馈可复核 |
| A09 无AI执行／复跑 | 已验证方案，关闭构建会话 | 执行仍可工作，普通批次无逐页LLM；版本和实际调用清楚 |
| A10 兼容环境复用 | 在另一兼容环境导入方案 | 检查兼容、验证／灰度后新任务运行；不靠原私有路径、Cookie或会话ID |
| A11 分类／分页与语言 | 混合sitemap、型号目录、浅层商品路径、多语言和持续下一页 | 不把目录当单品、不因路径陌生排除；分层取证并持续有效后续，模糊语言分支说明 |
| A12 访问与会话错误 | 429、200挑战壳、404、依赖缺失、子页重挑战 | 分类准确、有限退避、正常资源错误不无限升档；批量复用会话并回收 |
| A13 中断与取消 | 重复提交、进程异常、执行中取消；承诺暂停／恢复时执行 | 数据不重复、进度可解释、迟到结果不接纳，自建进程资源实际结清 |
| A14 导出保真 | 中文、引号、逗号、换行、HTML、属性分隔符、疑似公式；任务报告含部分／缺失异常索引 | CSV可正确读取，9列业务值与源记录一致；部分／缺失／格式在任务报告可辨，表格安全策略明确 |
| A15 漂移及修复 | 模板价格或正文变化导致字段失效 | 停止错误扩散，标受影响旧数据，修复后含失败场景的真实灰度；不筛掉难页 |
| A16 用户管理 | 创建、查看、控制、构建会话暂停／取消／移除、返回、导出及失败恢复 | 操作真实，区分命令请求与实际执行；页面关闭不停止后台；未知总量无伪百分比 |
| A17 覆盖与人工验收 | 有明确后续却因预算停；用户认为覆盖够用 | 记录人工验收者／依据及业务状态；系统仍保留预算停止、剩余入口与范围未知 |
| A18 基础字段与分块描述 | 名称、正价、币种、停售有价、`none.jpg` 占位图、Description 仅适配/清单、政策同模块、`OnlineOnly` | 基础字段有来源；停售不因有价当可售；占位图不算主图；描述按 section 分块，适配/清单归关系字段，政策排除；`OnlineOnly` 不映射为库存状态 |
| A19 纯发现任务 | 只声明发现能力、不声明 `extract`；入口或分类页有商品链接 | 输出 URL 清单；不请求商品页；URL 计数不变量成立；不把 URL 数写成商品数 |
| A20 多任务并行 | 两个任务同时运行；至少一个同域；运行中暂停／取消其中一个 | 各任务状态、计数和输出互不污染；同域请求受限速；一个任务暂停／取消不影响另一个；迟到结果被拒收 |

每条场景注明通过、失败、未运行或不适用及理由。不适用须来自承诺范围，不能因为缺工具就把承诺项划掉。A08～A10的方案保存、执行与导入按[采集方案与兼容契约](08-采集方案与兼容契约.md)检查，不能只看命令能否运行；A13、A16的状态、计数与迟到结果按[任务状态与计数契约](09-任务状态与计数契约.md)检查；A19、A20 的规则类型和并行模型按[采集规则与任务运行时](19-采集规则与任务运行时.md)检查。

## 代表性组合

至少用业务需要的不同路径评价：公开结构化商品数据、普通HTML、分类／分页差异、多层目录（品牌／型号／零件等）、必要动态页面、不同字段模板。多层目录路径要验证“浅层取核心字段、详情按需补全”的深度决策，不能只证明能抓到详情页。多个同平台主题的成功不能替代这些路径。完整候选入口见[验收基准站点](12-验收基准站点.md)。

跨路径代表性与公开访问能力分别记录，实际范围由团队在D01中确认。不要求先攻克所有困难站，不因单站复杂就放宽其他站字段要求。

## 基准站点与阶段验收

原需求提供的完整站点名单（法国母婴、美国户外、德国模型及其他案例）已作为**基准集**保存在[验收基准站点](12-验收基准站点.md)。它是扩展评估和回归的候选池，不是当前可采结论，也不是阶段验收的逐站通过线。

阶段验收按 D01 选定的 5～8 个代表站执行，覆盖公开结构化数据、普通 HTML、分类／分页差异、必要动态页面等路径；站点、范围、通过线和签字人填写在 [D01验证模板](14-D01验证模板.md)。基准集用于后续广度和回归评估；报告不得删除失败站或把未测站写成通过。

下表保留首批历史候选，便于快速定位；完整名单以 12 为准。

| 公开入口 | 历史关注点 |
| --- | --- |
| [skatepro.es](https://www.skatepro.es/) | 体育用品、公开选项与不同商品形态 |
| [javaestate.com](https://javaestate.com/) | 食品、目录与限流处理 |
| [makpoint.es](https://www.makpoint.es/) | 网络地区、站点地图与HTML获取 |
| [bedbathandbeyond.com](https://www.bedbathandbeyond.com/) | 动态访问、目录与商品入口差异 |
| [shopthebulkstore.com](https://www.shopthebulkstore.com/) | 食品、无明显sitemap时的发现和访问差异 |

使用前确认访问边界、站点当前结构、任务资源及实际目标。不要只因为某站以前易采，就把它替代普通HTML或动态路径的真正验证；也不要把基准集里的一次成功当成全站或长期结论。

## 结果比较与报告模板

| 维度 | 记录方式 |
| --- | --- |
| 样本集合 | 预先固定站点、入口、市场／语言及范围，失败后不能移除站点提高分数 |
| 构建成本 | 总耗时、真实模型供应商／模型／调用及重试、人工介入、修订次数 |
| 运行效率 | 执行版本、网络／代理条件、观测时间窗、实际请求与有效商品数；配置RPS不等于实际吞吐 |
| 采集深度 | 各页面层级请求数、每有效商品请求数、每有效商品下载字节、发现阶段每100请求新增唯一实体URL、入口贡献/重叠、重复率、部分枚举、浅层字段命中率、详情补全比例 |
| 质量 | 基础字段核对、正价有效数、部分正文／摘要回退／未提供／失败分别统计、占位图与停售状态 |
| 完成情况 | 自然结束、预算停止、用户停止、访问失败、质量阻塞及剩余工作 |
| 支持范围 | 自动完成、人工辅助完成、失败、未完成分别列；约70%是规划目标，不预写成实测 |
| 复用与维护 | 新环境复用的步骤和结果；模板变化需要改多少站点代码或公共代码 |
| 资源 | 自建浏览器／进程的启动及回收数量；未确认回收先停止新增 |

最终报告附完整有效结果、排除／失败清单和已知限制。小样本只能证明相应路径，不替代全量；人工满意不覆盖系统真实停止原因。
