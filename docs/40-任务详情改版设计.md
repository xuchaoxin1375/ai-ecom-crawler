## 用途与边界

本页是[React v2 前端改进待办](frontend-backlog.md)推广计划阶段 3 的设计草案：在不改后端接口、状态契约、已分享深链接、React 外壳和视觉令牌的前提下，重组采集任务详情。

默认先显示任务结果：商品任务先见商品结果，网址发现任务先见网址结果；质量反馈、数据明细和运行事实移到各自入口；导出只保留一个常驻入口。站点详情和构建详情不在本阶段。

本页的视图名称、质量反馈分组、CSV 与明细去向已经项目方确认按推荐方案执行，见“已确认决策”。实现记录和未覆盖项见文末。

## 首屏结构与 HTML 草稿

线框主稿是可浏览的静态 HTML：`experiments/d08/task-detail-prototype/index.html`。打开方式、状态切换和覆盖点见该目录 `README.md`；1280 和 390 截图在仓库外 `workbench/task-detail-prototype-20261125/`。下方文字只固定内容顺序和验收口径，不替代实际原稿。

| 顺序 | 内容 | 桌面 | 窄屏 |
| --- | --- | --- | --- |
| 1 | 返回、任务标识、状态／结果／类型／旧规则徽标 | 同一行，标题左、状态右 | 标题和状态换行，返回在上 |
| 2 | 站点、批次、停止原因、更新、实时／轮询状态 | 标题下方一行或多行 | 换行，站点和批次链接保留 |
| 3 | 主操作、更多、刷新 | 页头右侧同一行 | 按钮换行，主操作仍先出现 |
| 4 | 旧规则提示（有则显示） | 概览之前，整行 | 同左 |
| 5 | 紧凑摘要：结果数、失败／排除、覆盖、质量异常 | 四列 | 两列，360 像素以下单列 |
| 6 | 视图切换：数据明细、质量与验收、运行明细 | 标签栏 | 单选控件 |
| 7 | 数据明细（默认） | 商品任务：CSV 预览 + 全部商品明细；网址任务：网址明细 | 同顺序，单列，表格在容器内滚动 |

任务详情默认进入数据明细，首屏直接看到 CSV／网址明细和顶部结果计数；不再单独放大商品预览卡。任务没有有效结果时，CSV 和明细各自显示空态，质量与验收仍从 tab 进入。

## 操作位置

| 位置 | 放什么 | 约束 |
| --- | --- | --- |
| 页头 | 当前对象、状态、一个随状态变化的主操作 | 运行中突出暂停／继续；终态突出导出；同一后果不在其他区块重复常驻 |
| 「更多」 | 导出（主操作不是导出时）、取消任务、复制 ID、归档／恢复、打开站点／批次 | 取消保留二次确认；导出只出现一次 |
| 质量与验收 | 结果验收、质量异常、反馈动作 | 从数据明细可进入；处理后可回原任务 |
| 数据明细 | CSV 预览、全部商品／网址明细、空结果说明 | 商品任务显示 CSV 和商品明细；网址任务只显示网址明细；默认视图 |
| 运行明细 | 任务事实、规则版本对照、内容完整度、流状态 | 低频率技术信息，不与结果争首屏 |

导出范围沿用现有文案：任务导出只包含当前任务的有效商品和失败记录；任务仍在运行时使用部分导出。

## 状态表

| 任务状态 | 数据明细 | 页头主操作 | 更多与辅助入口 |
| --- | --- | --- | --- |
| 草稿或排队 | 空结果，说明尚未开始 | 取消任务 | 复制 ID；批次／站点 |
| 运行中或暂停中 | 已产生结果优先，显示实时／轮询 | 暂停任务 | 导出（更多）、取消（更多）、数据明细 |
| 已暂停 | 已有结果，说明可从暂停点继续 | 继续任务 | 导出（更多）、取消（更多）、数据明细 |
| 正在取消 | 已有结果保留 | 无 | 导出（更多）、复制 ID |
| 完成 | 结果与质量摘要 | 导出 ZIP | 质量与验收、数据明细、复制／归档／站点 |
| 部分完成或失败 | 结果与质量异常摘要 | 导出 ZIP | 质量与验收（带异常数）、数据明细、归档 |
| 已取消 | 部分结果或空结果 | 导出 ZIP | 质量与验收、数据明细、站点／批次复跑 |
| 归档 | 结果仍可查看 | 导出 ZIP | 恢复任务；站点／批次 |
| 结果为空且已结束 | 数据明细内空状态，质量与验收仍可从 tab 进入 | 导出 ZIP | 质量与验收、数据明细 |
| 读取失败 | 错误说明与重试 | 无 | 返回全部任务 |

任务结果基于旧规则时，旧规则提示固定在摘要之前；不要让用户先看到旧数字再在侧栏发现规则过期。

## 视图与内容去向

| 视图 | 内容 | 来源 |
| --- | --- | --- |
| 数据明细 | CSV 预览（主图列缩略图复用商品预览弹窗；描述可切换单行／换行，点击打开完整描述；表头“预览设置”在原页弹窗调整图片代理、列表缩略图和实时数据预览条数）、全部商品明细；网址任务显示网址明细 | 现有 `TaskCsvPreview`、`TaskItemsSection` |
| 质量与验收 | 结果验收、反馈记录、质量异常明细、打开修复／复跑 | 现有 `FeedbackPanel`、`QualityExceptionsSection` |
| 运行明细 | 任务事实、规则对照、内容完整度、更新与流状态 | 现有任务事实与内容完整度区块 |

已确认：任务详情不再保留「结果」大商品预览视图；商品任务默认进入数据明细，网址任务的数据明细直接显示网址列表；质量与验收和运行明细保留。

## 深链接映射

- 现有 `/tasks/{taskId}` 保持不变；站点、批次和任务列表的深链不受影响。
- 视图用查询参数表达，候选为 `?view=quality|data|detail`，默认 `data` 省略；旧的 `?view=results` 映射到数据明细并清理，无效值回到数据明细并用 `replace` 修正。
- 同一页面切换视图用 `replace`，不把每次切换写入浏览器历史；浏览器后退仍回到进入任务前的页面。
- 站点、批次链接继续使用现有路由；从数据明细进入质量与验收再返回时保留任务 ID 和当前视图，不改变已分享链接。
- 不新增全局路由，不改变任务、站点、批次和构建路由。

## 组件与数据复用

- 复用现有 React 外壳、颜色令牌、`Badge`、`Button`、`DropdownMenu`、`InlineNotice` 和确认弹窗。
- 复用 `TaskItemsSection`、`TaskCsvPreview`、`QualityExceptionsSection`、`FeedbackPanel`，不改它们的 API 和状态契约；`ProductPreviewSection` 随结果视图一起退役。
- 任务状态、计数、停止原因、规则过期和导出范围继续使用 `taskIsActive`、`taskRuleIsStale`、`taskExportUrl` 等现有判据。
- 不新增后端接口，不改任务状态、计数、反馈或规则激活契约。

## 响应式与可访问性

- 1280 × 900 和 390 × 900 为首要对照，768 和 320 为交付前检查。
- 390 首屏至少看到任务名、状态、主操作和数据明细的第一块内容；商品任务优先露出 CSV 表头，网址任务优先露出第一条网址。
- 视图切换支持键盘；窄屏用单选控件；关闭弹窗后回到触发按钮。
- 表格和长文本只在自身容器内滚动，不产生页面级横向溢出；CSV 长行可横滚，页面仍纵向滚动。
- 错误、空结果、读取失败和实时更新状态不只用颜色表达。

## 验收清单

- 覆盖运行中、终态、部分结果、真实空结果和读取失败；商品任务与网址任务分别走通。
- 状态、计数、结果明细与下载内容一致；导出只出现一个常驻入口，当前任务之外的历史任务不混入。
- 用户能从结果进入质量与验收，创建或分诊反馈后再回到原任务；关闭弹窗后焦点回到触发处。
- 旧规则提示在摘要之前可见；归档任务仍可查看结果和导出。
- 1280、768、390、320 无页面级横向溢出；首屏出现关键数据；键盘切换视图正常；桌面 axe 违规为零。
- 现有前端测试、lint、typecheck、format、build 和浏览器冒烟通过；真实账本只读走查，写操作在隔离账本验证。

## 已确认决策（2026-11-25）

项目方确认 D1–D6 全部按推荐方案执行：

| 编号 | 决策 | 采用方案 | 备选与代价 |
| --- | --- | --- | --- |
| D1 | 视图组织方式 | 页内视图切换，`view` 写入查询参数 | 全部折叠区：实现简单，但首屏仍可能堆叠；独立子路由：链接更清楚，但改动现有 URL 结构 |
| D2 | 质量与验收分组 | 合并结果验收和 quality exceptions | 分成两个视图：职责更细，但入口增加、反馈链路变长 |
| D3 | CSV 与全部明细 | 合并到「数据明细」，CSV 在上、全部明细在下 | 分成 CSV 和明细两个视图：更专注，但低频入口过多 |
| D4 | 网址发现任务 | 结果视图直接显示网址明细；隐藏商品 CSV 和商品质量入口 | 保留完整四视图：结构统一，但出现不适用内容 |
| D5 | 导出入口 | 终态页头主操作；运行中放「更多」 | 固定页头常驻导出：可见性高，但运行中主操作会被稀释 |
| D6 | 任务事实位置 | 独立「运行明细」，含规则对照和内容完整度 | 保留右侧事实栏：桌面可并排，但挤压结果和 CSV |

## 实施切分

1. 先搭页头、紧凑摘要、视图切换和唯一导出入口，保留现有任务查询、SSE 和轮询。
2. 商品任务把商品预览放结果视图；网址任务放网址明细；把结果验收、质量异常、CSV、全部明细和任务事实移到各自视图。
3. 按状态表接主操作与「更多」，处理空结果、部分结果、旧规则、归档和读取失败。
4. 补组件测试、浏览器走查、1280／390／768／320 截图和 axe；通过后再处理构建详情和全局导航。
