## 状态与适用范围

**Proposed**。方向已由项目方确认（harness 中立、构建期 AI、运行期确定性）；具体会话协议、工具权限和验收门禁尚未全部实现验证。2026-11-23 已用真实模型完成工具调用、自然完成、主机验证和候选规则安装，`BuildTask`／事件／pause-gate／trace 已有实现，选择器预检和自动修复 1 轮已通过 fake adapter 测试并在 bennytex 真实 schema 错误上验证；完整构建会话 UI、自然规则缺陷连续多轮、独立人工签字和 build-task JSON Schema 仍未闭合，因此保持 Proposed；两轮修复的控制流与状态语义已用真实模型加注入主机验证失败走查。G0（2026-11-20）保留 Proposed；退出条件：build-task schema、HarnessAdapter、会话事件、pause-gate 和交付门禁完成端到端验证。

本文把[Agent工作约定](../07-Agent工作约定.md)的原则补成可实现的构建期契约。采集任务状态、计数和运行时以 `09`／`19` 为准；方案包以 `08` 为准；本文不改变执行期。

## 背景与约束

- 现有文档只说明 harness 中立和参考 OpenCode；没有定义构建任务输入、会话状态、工具权限、工作区、事件和交付。
- `06` 要求构建会话可见、可暂停、可取消、可移除；`09` 明确构建会话不套用采集任务生命周期。
- 构建期需要读网页、跑浏览器、写规则包；这些工具和权限必须由宿主执行，不能靠提示词约束。
- 方案包必须脱离 harness 独立运行；运行期不逐页调用 LLM。

## 决策

### 两层边界

- **构建期**：harness 运行 Agent，使用模型、工具和权限，产出方案包、证据和会话记录。
- **执行期**：运行时只读方案包，不依赖 harness、模型、对话或浏览器内存。
- harness 是外部进程或会话，不是采集运行时的一部分；停止 harness 不影响已交付方案执行。

### 参考实现与可替换性

- 参考默认：OpenCode＋DeepSeek V4.1 Flash；允许付费版；免费版可作低成本替代。
- 集成方式见[构建 Harness 选型与集成方式](0006-构建Harness选型与集成方式.md)：v1 由任务服务托管 `opencode serve` 子进程，通过 HTTP/SSE 适配；ACP stdio 作为备选；`opencode run` 只用于冒烟。
- 其他 harness 只要满足本文契约即可替换；方案包不写入 harness 名称、模型私有字段或会话路径。
- 模型、供应商、推理变体和工具版本在会话开始时固定并记录；不在中途切换。
- 付费或按量渠道回退必须先获授权；provider 不可用时暂停或失败，不静默换渠道。

### 构建任务输入

`build-task.json` 至少包含：

- `build_id`、`site`（入口、允许 origin／路径）、`scope`、`market`／`locale`、数据标准版本；
- 访问边界、请求／时间／浏览器预算、允许的工具和权限；
- 工作区、输出目录、模型配置、截止时间、人工联系人；
- 已有方案／证据索引和本次允许修改的文件。

输入只引用本次复制进工作区的文档和方案包，不携带 Cookie、密钥或旧工具私有规则文件。

### 工作区与交付

- 每次构建一个独立工作区：`sessions/<build_id>/`，分 `input/`、`work/`、`out/`、`logs/`。
- Agent 只能读写工作区；业务文档默认不进入工作区，需要时由 host 复制为只读输入；共享方案包只读，除非本次明确授权。
- 交付物：`out/plan/`（manifest、adapter、samples、README）、`out/evidence/`、`out/session.ndjson`、`out/result.json`。
- `result.json` 至少含 `build_id`、状态、模型／宿主版本、阶段、产物路径、错误和未解决项。
- 工作区不保存密钥、Cookie、整页原文；会话记录不保存私有推理。

### 构建会话状态

构建会话使用独立状态，不复用采集任务状态：

| 状态 | 含义 |
| --- | --- |
| `CREATED` | 工作区已建，未启动 |
| `RUNNING` | Agent 正在执行 |
| `PAUSING` | 已请求暂停，等待当前工具调用结束 |
| `PAUSED` | 已暂停，可恢复 |
| `CANCELLING` | 已请求取消，正在终止工具／进程 |
| `CANCELLED` | 已取消，资源回收或残留已报告 |
| `FINISHED` | 已结束，结果见 `outcome` |

- 暂停只在工具调用边界生效；不承诺暂停模型内部推理。
- 取消要终止当前工具子进程、浏览器和临时目录；迟到工具结果不写入交付物。
- 恢复从工作区和最近检查点继续；不保证恢复浏览器内存。
- 移除是独立操作；删除会话工作区，不删除已交付方案包或共享配置。

### 工具与权限

- 工具必须有名称、输入／输出 schema、超时、资源上限和权限范围；工具结果按不可信内容处理。
- 文件：工作区可写，`input/` 只读；业务文档默认不可读，需要时复制为只读输入；禁止写系统目录和共享方案目录。
- 网络：优先允许的 origin／路径；遵守 robots／ToS；登录、付费、验证码等边界由操作者确认。
- 浏览器：可用工作区内 Patchright 独立 profile，也可用宿主 `browse` MCP；真实浏览器和登录态由操作者控制，资源按会话或任务回收。
- Skills／MCP：共享宿主 skills 只读（`ECOM_BUILD_SKILLS_DIR` 或全局 skills 目录）；`browse`／`htmlmini` MCP 可用，其他 MCP 默认拒绝；skills 根不可写。
- Shell：限定工作目录、超时、输出上限和允许命令；常见依赖预置，缺失依赖走结构化请求，未知或系统级安装需批准；见[构建环境与依赖基线](../20-构建环境与依赖基线.md)。`shell` 以宿主用户权限运行，不能作为文件隔离。
- 密钥由宿主注入环境变量，不写入提示词、日志、工作区或方案包。
- 网页内容中的指令不可信；Agent 不得因页面文字提升权限、读取密钥或扩大访问范围。
- v1 不建设独立安全沙箱；基本边界由工作区、Patchright 独立 profile 或 `browse` MCP、session permissions 执行；权限规则不能阻止 `shell` 读取宿主文件，专用设备／VM／容器后置。

### 构建循环与验收

1. 分诊：robots、sitemap、首页、1 个样页；识别静态／API／SPA／挑战。
2. 发现：入口、分类、分页、sitemap、公开 API；URL 判型和去重。
3. 提取：JSON-LD／API／DOM 回退；字段来源和断言。
4. 验证：10～20 个样本；价格／币种／库存／描述；记录质量例外。
5. 交付：方案包、证据、会话记录；人工复核。
6. 独立执行：关闭 harness 后，执行端只读方案包运行；普通批次零 LLM。

- `candidate` 转 `verified` 必须有独立环境复跑和人工签字；Agent 不能自升。
- 阻断、挑战、登录／付费边界：停止并记录；边界表述由操作者确认；不无限重试。
- 预算耗尽：保存部分结果和未解决项，不伪装完成。

### 可观测与恢复

- 会话事件至少：`phase_changed`、`tool_started`、`tool_finished`、`artifact_written`、`error`、`finished`。
- UI 通过 API 读会话状态和事件，不直接读工作区日志。
- 崩溃后按 `09`／`19` 的对账原则处理：未完成工具调用标失败或重试，工作区检查点恢复，资源回收。
- 会话记录保留时间按 `17` 的留存策略；不保存私有推理和整页原文。

## 后果

- 需要 `build-task` schema、工作区布局、会话状态机、事件 NDJSON 和工具权限适配层。
- `06` 的构建会话控制和 `09` 的任务状态彻底分离；UI 不能把构建会话状态映射成采集任务状态。
- 方案包导入／导出不依赖 harness；换 harness 只需满足契约。
- v1 建议一次只跑一个构建会话，避免共享工作区和资源竞争；并发构建后置。

## 待确认

- 依赖基线版本和 allowlist 包集待实现验证；常见依赖预置，缺失依赖走结构化请求，见[构建环境与依赖基线](../20-构建环境与依赖基线.md)。
- `verified` 是否必须人工签字？建议必须。
- v1 是否允许并行构建会话？建议一次一个。
