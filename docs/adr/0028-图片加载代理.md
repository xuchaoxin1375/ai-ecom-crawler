## 状态与适用范围

**Accepted**（2026-11-27，验证 partial）。本 ADR 决定商品预览图片改为同源服务端取图，并允许系统设置选择自动、指定或直连模式；自动模式按任务代理、服务默认代理、系统图片代理、直连的顺序尝试，指定模式不回退直连。

本 ADR 只覆盖商品图片显示。采集、构建和规则验证的代理仍按[构建环境与依赖基线](../20-构建环境与依赖基线.md)执行；任务定义里的 `proxy` 仍是出口事实来源。设计细节见[图片加载代理设计](../52-图片加载代理设计.md)。

## 背景

任务和站点已经有代理出口，但商品图片原先是浏览器直接请求 CDN。图片 CDN 按地区、IP、来源站或防盗链限制时，任务账本里的名称、价格和图片 URL 都存在，预览却缺图。浏览器端无法使用任务代理，也没有跨站点统一的图片错误处理。

同时，图片 URL 来自被采集站点，属于不可信输入。如果服务端直接按任意 URL 取图，会引入 SSRF、内网探测、超大响应和内容类型混淆风险。

## 决策

- 增加 `GET /api/media/image?url=...&task_id=...`，由服务端代取商品图片并返回 `image/*`。
- 增加 `GET/PUT /api/system/image-proxy`，在 `app_settings` 保存 `{mode, proxy}`；默认 `auto`。
- `auto` 的顺序是任务代理 → 服务默认代理 → 系统图片代理 → 直连，相同 URL 去重，直连是最后兜底。
- `specified` 只使用系统图片代理，失败直接报错，不静默直连；`direct` 不使用代理。
- 任务定义或批次站点已有的代理优先，系统设置只提供全局图片代理，不复制第二份站点代理配置。
- 前端所有商品图片显示经 `imageProxyUrl(url, taskId)` 走同源入口；复制 URL、下载和打开原图仍使用原 URL。
- 数据预览表头提供“预览设置”按钮，在当前页 Dialog 内复用系统设置的表单，不跳转页面；CSV 描述支持单行／换行，点击描述打开完整描述。
- 服务端取图只允许公网 HTTP(S)，最多 3 次重定向、8 MiB、20 秒；拒绝 SVG、HTML、私网地址、userinfo 和未知类型；每一跳重新校验主机。
- 成功响应允许浏览器缓存 1 小时；错误不缓存。首版不做服务端图片缓存。

## 备选与取舍

| 方案 | 结果 | 未采用原因 |
| --- | --- | --- |
| 浏览器直接加载原图 | 实现最轻 | 无法复用任务代理，地区/CDN 限制无法处理 |
| 前端配置浏览器代理 | 不改后端 | Web 页面不能可靠设置浏览器代理，环境绑定强，局域网客户端不可控 |
| 只支持系统全局代理 | 实现简单 | 多站点不同出口时无法复用任务代理 |
| 自动探测本机 mihomo/Clash | 少配置 | 端口、节点、凭据不可移植，容易把错误出口当成站点问题 |
| 服务端代理 + 自动/指定/直连 | 多一层取图代码和依赖 | 采用；出口语义可控，浏览器只依赖同源接口 |
| 首版加服务端磁盘缓存 | 减少重复取图 | 增加失效、磁盘配额和隐私问题；先依赖浏览器缓存 |

## 后果

- 生产依赖新增 `httpx` 和 `socksio`；socks5 代理可复用现有代理 URL 语义。
- 图片请求从浏览器直连变为服务端取图，服务端承担图片带宽和超时；大图受 8 MiB 上限约束。
- 自动模式的直连兜底会改变实际出口；需要固定地区上下文时使用指定模式。
- 目标 URL 的 DNS 解析和图片站点可达性成为新的失败点；错误只显示占位和重试，不影响任务账本。
- SSRF 校验基于解析时地址，仍存在 DNS 重绑定的理论窗口；后续可加域名白名单或独立网络隔离。

## 验证

- `test_image_proxy.py` 覆盖配置校验、优先级、去重、指定模式不回退、私网/协议/凭据拒绝、SVG/超限/重定向、设置 API 和取图 API；api 组 107 项通过，ruff 通过。
- 前端 179 项测试、lint、typecheck、format、build 通过。
- 只读临时实例连接真实账本：真实商品图返回 200、`image/webp`、66,868 字节；私网目标返回 400；临时实例已停止。
- 8765 已重启加载新后端；重启前运行任务已 `FINISHED / BUDGET_EXHAUSTED`。真实任务的实时数据、CSV 描述弹窗/换行和表头预览设置弹窗已走查；390 弹窗不溢出。
- 未验证：真实代理失败后的自动直连兜底、socks5 真实代理、需要 Cookie/Referer 的站点、服务端缓存和长时间大图压力。
