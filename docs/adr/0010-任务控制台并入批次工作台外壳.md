## 状态与适用范围

**Accepted（方向）**，验证状态为 **partial**。本 ADR 确认把内部任务控制台的主路径并入[批次工作台前端](0009-批次工作台前端技术栈.md)的 Vue 3 外壳，使用户从 `采集批次 → 批次详情 → 站点详情 → 全部任务 → 任务详情` 保持同一导航、视觉语言和操作上下文。旧 `/legacy` 原生页面保留为技术回退能力，不再作为主导航入口。2026-11-23 后续：v2 `/tasks`、`/tasks/{id}` 已承接任务列表、详情和结果验收反馈（见 [ADR 0012](0012-前端v2技术栈与设计系统.md)），本 ADR 的导航和信息归属决策继续有效；旧 Vue 任务页和旧 `/legacy` 于 2026-11-24 默认下线，仅 `ECOM_LEGACY_UI=on` 时回退。

本文不新增任务状态、计数口径或 API 语义；任务状态、控制和计数仍以[任务状态与计数契约](../09-任务状态与计数契约.md)为准，界面行为以[界面与任务管理](../06-界面与任务管理.md)和[v1 界面范围](../25-v1界面范围.md)为准。

## 背景

[ADR 0008](0008-前端技术栈与本地Web形态.md) 的原生任务控制台曾作为 v1 技术验收面；2026-11-23 批次工作台阶段 1 进入 v1 后，用户在批次外壳中点击“内部任务控制台”会跳到 `/` 的独立原生页面。两个页面使用不同导航、样式和操作节奏，任务信息被拆成两套入口；批次站点详情也只保留部分任务信息。用户反馈该页面突兀、孤立、直观性不足。

继续把旧页面作为主导航入口会保留两套设计系统和两套操作路径；只做 iframe 或换皮也不能统一信息结构和焦点路径。因此需要把任务列表、创建、筛选、详情、SSE、控制、归档、导出、质量和覆盖并入 Vue 外壳。

## 决策

- **主导航**：侧栏“全部任务”指向 Vue 路由 `/tasks`，任务详情为 `/tasks/{task_id}`；不再从主导航链接旧 `/legacy`。
- **信息归属**：任务列表保留任务 ID、类型、站点／方案、市场、状态、结果／覆盖、计数、质量和更新时间；任务详情保留状态、停止原因、有效／失败／排除、覆盖、质量异常、全部计数、商品／网址明细、SSE、控制、归档／还原和导出。
- **创建路径**：任务列表内提供技术创建表单（规则包、类型、预算和最大尝试），默认折叠，任务列表优先显示；创建后直接进入任务详情。
- **批次深链**：批次站点详情的任务操作区提供“在全部任务中打开”；任务详情提供“所属批次”和“批次站点”返回链路。
- **兜底**：旧 `/legacy` 原生控制台保留为技术排查入口，只在任务详情“技术详情与兜底入口”中出现；不继续产品化打磨。
- **接口**：复用现有 `/api/tasks`、`/api/rules`、`/api/tasks/{id}/*` 和 SSE；任务摘要补充 `started_at`、`finished_at`，不改变任务状态机。
- **验证证据**：真实批次与真实任务、1280／1440／768／390、分段截图、前端组件测试和后端回归。长页不再用单张 full-page 作为详细验收证据。

## 备选与不选理由

| 备选 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 保留旧 `/legacy` 独立页面，仅换视觉 | 改动最小 | 导航、操作和状态仍是两套；用户仍会丢失上下文 | 不采用 |
| 用 iframe 嵌入旧页面 | 不迁业务代码 | 焦点、滚动、SSE、深链和样式隔离仍不可控 | 不采用 |
| 只补批次站点详情的任务信息 | 工作量小 | 创建、筛选、任务列表和独立任务排障仍缺失 | 不采用 |
| 任务控制台并入 Vue 外壳 | 一套导航、一套设计语言、同一 API 和状态 | Vue 应用增大，旧页面保留维护成本 | 采用 |

## 后果与回退

- **收益**：用户不再在业务工作台和技术控制台之间切换设计和导航；批次站点、任务和结果可以直接下钻；任务创建、筛选、控制、归档和导出仍可用。
- **代价**：Vue 应用增加两个页面和任务相关 API 类型；旧 `/legacy` 页面暂时保留，存在双轨维护；需要持续用真实任务验证 SSE、控制和导出。
- **回退条件**：Vue 任务页出现阻断性状态/控制问题，或旧 `/legacy` 仍是唯一可用的技术排查入口时，可临时把侧栏“全部任务”指回 `/`；回退不改变任务账本和 API，恢复后继续使用 Vue 主路径。
- **复审**：跨浏览器、读屏、深色主题和更多真实任务验证后，再评估是否移除旧 `/legacy` 页面或把本 ADR 验证状态提高；不在没有证据时宣称完整 UI 验收。

## 验证记录

- 真实批次 `b-586052683409`：familidoo 6／6、decohappy 8／8，共 14 条有效商品、0 失败；decohappy 8 条质量异常。
- 任务列表筛选、归档／还原、批次站点到 `/tasks/{id}` 深链、任务明细分页和 8 条质量异常详情已走查。
- 1280／1440／768／390 无横向溢出，控制台错误 0；1280 长页按首屏、质量、明细分段截图，full-page 只作索引。
- 后端 204 个测试（后续加入构建工作流／trace）、Web API 14 个测试、前端 2 个 Vitest 用例、`vue-tsc`／Vite 构建和 ruff 通过。
- 证据：`experiments/d08/batch-workbench-e2e/`。
