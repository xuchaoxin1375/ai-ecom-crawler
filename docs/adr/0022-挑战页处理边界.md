## 状态与适用范围

**Accepted**（2026-11-26）。本 ADR 统一挑战页、验证码、浏览器指纹和会话风控的处理边界，取代此前“挑战页一律视为不可尝试的访问控制”的表述。涉及 `17` 的默认边界和逐站检查表，`00`、`01`、`03`、`08`、`10`、`13`、`14`、`16`、`19`、`21`、`22`、`23`、`27`、`30`、`37`、术语表和 `来源与维护` 的同类口径，以及 ADR 0005、0006、0007、0013、0020、0021 中把挑战页与登录／付费并列限制的表述。

本 ADR 不改变登录、付费墙、年龄门、地区限制、个人数据、ToS、当地法律、限速和留存边界。技术可行不等于获得授权。

## 背景

- 旧口径把挑战页和登录、付费、401／403 一起列为不可尝试的访问边界，要求人工或停止。
- 实现和证据已经越过旧口径：Scrapling stealth 在 `partsfornissans.com` 完成 target10 构建和执行；`campsaver.com` 用有头晚接入完成 30／30。
- 文档、构建 brief、运行期失败分类和实际操作不一致：一边要求停止，一边已有可复用的求解路径，构建 Agent 容易在已有能力时放弃。
- 项目方于 2026-11-26 确认：验证码、浏览器指纹、会话和出口等技术手段不另设禁令，以实际可行和证据为准；仍不越过登录、付费、年龄门、地区限制和站点明确拒绝。

## 决策

- **挑战页不是默认停止条件**：Cloudflare、PerimeterX 等挑战壳、验证码、指纹校验和会话风控，可以用成熟库、浏览器会话、有头晚接入或操作员协助尝试解决。
- **技术手段不另设禁令**：Scrapling `StealthySession`／`solve_cloudflare`、浏览器指纹处理、会话复用、出口切换、低批大小和有头晚接入都可按证据使用。每次只改一个关键变量，记录出口、客户端、请求数和结果。
- **仍然停止的边界**：登录、注册、付费墙、年龄门、地区限制、个人数据、站点明确拒绝（包括 ToS 明确禁止且没有书面许可）和法域限制；这些不因技术可行而放行。
- **失败照常记录**：求解后仍是挑战页、401／403 或空壳时，按 `blocked`／`ACCESS` 记录最终 URL、标题、客户端、出口、请求数和停止原因，不把挑战页当内容。
- **不承诺通过率**：单站、单出口的一次通过不是长期结论；站点风控会变化，结论有时效，同一出口可能先成功后挑战。
- **工程边界不变**：预算、并发、限速、留存、证据和任务状态仍按 `09`、`16`、`17`、`19`、`22`、`23` 执行；挑战求解耗时计入浏览器验证预算。

## 实施

- 运行期：`static`、`browser` 保持各自能力边界；需要求解挑战时使用 `stealth`。`browser` 的 `challenge_wait_ms` 只等待页面自己完成验证，不点击、不代答验证码。
- 构建：brief 提供 challenge 路径和 Scrapling 探针；只有样本返回真实商品内容时才写 `default_engine: stealth`，stealth 仍被挡时记录 `ACCESS` 并停止。
- 合规：逐站仍填 `17` 的检查表；挑战求解不替代 ToS、当地法律、速率和留存判断。
- 文档：`17` 是合规口径入口，`19` 是运行时能力入口，本 ADR 记录边界与替代关系。

## 后果

正向：

- 文档与实现一致，不再要求构建 Agent 在已有可用能力时把挑战站直接判为不可采。
- 挑战站有统一评估路径，减少重复 headless 矩阵和临时脚本。
- 登录、付费、年龄门、地区限制和明确拒绝仍然单独受控，不因挑战放行被一起放开。

代价：

- 挑战求解的耗时和成本更高，失败原因更多；需要记录出口、客户端和请求数。
- 站点风控变化会让结论过期，不能把一次通过写成长期能力。
- 指纹、会话和出口手段涉及 ToS 与法律判断，仍需逐站核对。

## 验证与证据

- `partsfornissans.com`：Scrapling stealth 构建 6／6、执行 10／10，0 失败、0 质量异常；证据在仓库外 `workbench/partsfornissans-2026-11-26/`。
- `campsaver.com`：有头晚接入 30／30；证据见 `experiments/d01/campsaver/` 和 `12` 的复核段。
- 本地单测：stealth 引擎配置、挑战标题、listing 拒绝和会话关闭；见 `app/tests/`。
- 文档检查：链接、示例和导出复核。

## 替代方案

- **保持挑战页一律停止**：最保守，但与已落地的 stealth 引擎和 partsfornissans 证据冲突，会让构建 Agent 放弃可用路径。
- **只允许有头晚接入**：不引入求解库，但覆盖不了无人值守和 Cloudflare 类挑战，人工成本更高。
- **技术可行即全部放行**：会把登录、付费、年龄门和地区限制也混进来；本 ADR 明确保留这些边界。
