## 状态与适用范围

**Proposed**（2026-11-27）。本 ADR 决定在 `serve` 和系统设置页增加显式的开发模式，让本机回环请求跳过访问密钥校验，同时保留局域网认证、Host 校验、同源写保护和原有登录页。它修订 [ADR 0019](0019-访问密钥登录页与会话认证.md) 的访问判定，但不改变密钥存储、会话格式或失败限流。

范围只覆盖开发便利。TLS、多用户、公网暴露、逐设备会话撤销和访问密钥找回仍不在范围内。设计细节见[开发模式本机免登录设计](../54-开发模式本机免登录设计.md)。

## 背景

[ADR 0019](0019-访问密钥登录页与会话认证.md) 的登录页解决了浏览器凭据输入和会话问题，但开发期仍有摩擦：

- 开发实例 8765 通常以 `--host 0.0.0.0` 启动，账本已保存访问密钥；从本机 `127.0.0.1` 打开也要先登录。
- 编码 agent 不持有用户的访问密钥，真实实例登录后的走查只能交给项目方。
- 每换一个浏览器 profile 或清理 Cookie，都要重新输入密钥，降低界面迭代速度。

删除或重置密钥会影响局域网设备和其他脚本，不适合作为日常开发开关；需要的是一个明确限定在本机、可随时关闭的旁路。

## 决策

- **启动参数**：`serve --dev-no-auth` 对当前进程开启本机免登录；与 `--host 0.0.0.0` 兼容。
- **设置页开关**：`/settings` 的“访问与认证”增加“本机开发免登录”开关，通过 `PUT /api/system/access/dev-no-auth` 切换并持久化到 `app_settings.serve_dev_no_auth`。
- **生效范围**：只有 TCP 对端为回环地址且 Host 头为 `127.0.0.1`、`localhost` 或 `::1` 的请求跳过访问密钥；其他请求继续走会话、Basic 和登录页。
- **判定顺序**：Host 允许和局域网开关先校验；开发模式不绕过这两层，也不绕过写请求的同源 `Origin` 与 `X-Requested-With`。
- **优先级**：`--dev-no-auth` 对当前进程强制开启；此时设置页开关只读并显示来源。启动参数关闭时，账本设置值决定行为。
- **持久化与回滚**：只新增 `app_settings.serve_dev_no_auth`，不修改 `serve_token`、`serve_lan_enabled` 或会话格式；关闭开关或去掉参数重启即可恢复原认证。
- **可观测性**：`GET /api/system` 暴露 `dev_no_auth_setting`、`dev_no_auth_active`、`dev_no_auth_forced`；设置页和页眉持续显示开发模式提示。
- **只读模式**：开关不可写，由既有只读中间件返回 `403 READ_ONLY`。
- **接口限制**：开关接口只接受回环客户端且回环 Host；强制开启时返回 `409 DEV_MODE_FORCED`，非回环调用返回 `403 DEV_MODE_LOOPBACK_ONLY`。

## 备选与取舍

| 方案 | 结果 | 未采用原因 |
| --- | --- | --- |
| 只提供启动参数 | 实现最小、不写账本 | 日常切换要重启并记住参数；页面无法发现当前状态 |
| 只提供设置页开关 | 切换方便 | 首次被登录挡住，无法自举；编码 agent 仍进不去 |
| 启动参数 + 设置页开关 | 首次和日常都可用 | 需要定义优先级和提示；采用 |
| 所有客户端免登录 | 最省事 | 会把无认证面板暴露到局域网，破坏 ADR 0019 边界 |
| 仅回环绑定才允许免登录 | 边界最严格 | 当前 0.0.0.0 开发实例需要先改启动命令，削弱开发便利 |
| 只检查 Host 头 | 实现简单 | 局域网客户端可伪造 Host；不能作为认证边界 |
| 只检查客户端 IP | 支持本机代理 | 本机反向代理可能把外部请求变成回环请求；与 Host 联合判定更稳 |
| 删除或重置访问密钥 | 无新增代码 | 影响所有设备和脚本，开发结束恢复成本高 |
| localStorage 前端旁路 | 不改后端 | 后端仍返回 401，无法真正免登录 |

## 后果

- 开发模式开启时，本机任何能访问 8765 的进程都无需密钥；这与本地账本访问属于同一信任边界，但会扩大本机自动化脚本误操作的可能。页面和启动日志必须持续提示。
- 本机反向代理只有在 Host 也是回环名称时才命中旁路；外部域名转发不会免登录。仍不建议把开发模式和不可信本机代理同时使用。
- 设置持久化后，开发者换任务或交接前需要检查页眉提示或 `serve_dev.py status`；忘记关闭不会影响局域网认证，但会让本机继续免登录。
- 开发模式下本机“退出登录”不会让下一次请求回到登录页；界面禁用该按钮并说明，避免误解。
- `/api/system` 新增三个字段，OpenAPI 快照和前端类型需要同步；不新增数据表或迁移。
- 旧代码忽略新设置键；回滚不需要清理数据库。
