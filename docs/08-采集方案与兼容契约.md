## 用途与边界

本文件定义**可保存、可执行、可导出导入的采集方案**的最小结构。它约束的是方案的外壳和交接信息，不规定团队必须使用某种语言、框架或规则格式；声明式规则、站点程序或两者混合都可以，只要满足本契约并能被兼容执行端读取。

方案是 AI 构建、框架执行、团队交接的共同单位。它必须能脱离构建会话独立存在，不依赖私有对话、个人路径、临时浏览器内存或未记录的隐含条件。方案包不包含任务进度、结果数据、审批状态、Cookie、密钥或整页原文。

字段名是契约，序列化格式可以是 YAML、JSON 或其他可机器读取的形式；实现方必须提供到本契约的无损映射。示例中的站点、选择器和值均为合成内容，不构成真实站点证据。

## 方案包结构

方案包可以是一个目录，也可以是一个压缩包；包内路径使用相对路径和 `/` 分隔符。

| 部分 | 必需 | 内容 |
| --- | --- | --- |
| `manifest` | 是 | 方案标识、版本、站点与范围、发现／获取／提取／校验的摘要或引用、兼容信息、证据状态 |
| `rules/` 或 `adapter/` | 视方案类型 | 声明式规则、站点程序或混合实现；由 manifest 指向实际入口 |
| `samples/` | 否 | 合成样本或获准使用的样本网址与期望值；默认不保存整页原文 |
| `README` | 否 | 运行、停止、复跑和维护说明；不能替代 manifest 中的必需字段 |

manifest 是方案的入口；执行端先读 manifest，再按 `kind` 和入口字段加载规则或程序。没有 manifest 的方案只能算临时脚本，不能作为可复用交付。

## 最小 manifest 字段

| 字段 | 必需 | 含义与约束 |
| --- | --- | --- |
| `schema_version` | 是 | 本契约版本。执行端不认识的版本应拒绝加载，不能猜测兼容 |
| `plan_id` | 是 | 稳定的站点／方案标识，不包含任务编号、用户信息或本机路径 |
| `plan_version` | 是 | 方案版本；提取规则、入口范围、字段来源或校验条件发生实质变化时递增 |
| `kind` | 是 | `declarative`、`program` 或 `hybrid`，决定执行端如何加载方案 |
| `status` | 是 | `candidate`、`verified` 或 `deprecated`；表示方案成熟度，不是用户对任务的验收状态；`verified` 必须有可核对的证据 |
| `created_at`／`updated_at` | 是 | ISO 8601 UTC 时间；表示方案本身的修改时间，不是任务运行时间 |
| `site` | 是 | 站点名称、入口网址、允许的 origin／路径前缀、目标市场、语言和币种 |
| `scope` | 是 | 包含／排除范围、默认全量或明确的数量／采样限制、业务备注 |
| `discovery` | 是 | sitemap、分类、分页、商品网址判型和身份去重规则；至少说明一种发现路径 |
| `fetch` | 是 | 默认获取方式、按网址类型的覆盖、等待／动作、会话或 profile 需求、并发、重试和超时 |
| `extract` | 是 | 到[数据标准](02-数据标准与导出.md)字段的映射：来源类型、选择器／路径、必需或可空、回退 |
| `normalize` | 是 | 价格／税价／币种、正文清洗与状态、名称清理、选项处理；不能只写“按标准”而不给实现入口 |
| `validate` | 是 | 必需字段、正价、内容断言、部分描述与摘要回退策略、失败分类 |
| `runtime` | 视方案类型 | 程序／混合方案的启动入口、检查点、幂等键、取消与资源回收；声明式方案可写执行端默认值 |
| `compatibility` | 是 | 支持的操作系统、运行时、浏览器／引擎、依赖锁或版本范围、网络与地区假设 |
| `entrypoint`／`rules` | 视方案类型 | 程序入口或规则文件相对路径；不得指向方案包外的本机绝对路径 |
| `evidence` | `verified` 时必需 | 样本网址、期望字段值、验证时间与环境、已知限制和未验证项 |
| `notes` | 否 | 维护提示、已知模板差异、后续观察点；不能替代上述必需字段 |

`site`、`scope` 和 `discovery` 共同回答“采哪里”；`fetch` 回答“怎么拿到”；`extract`／`normalize`／`validate` 回答“拿到后怎么算合格”；`runtime`／`compatibility` 回答“换一个执行端还能不能跑”。任务状态、计数和取消后的迟到结果见[任务状态与计数契约](09-任务状态与计数契约.md)。

## 最小示例

以下仅为结构示例，不是可直接运行的方案，也没有访问过示例地址。

```yaml
schema_version: "1.0"
plan_id: "shop-example-gb"
plan_version: "2026.11.18-1"
kind: declarative
status: candidate
created_at: "2026-11-18T00:00:00Z"
updated_at: "2026-11-18T00:00:00Z"

site:
  name: "Example Shop"
  entry_urls: ["https://shop.example/"]
  allowed_origins: ["https://shop.example"]
  allowed_path_prefixes: ["/products/", "/collections/"]
  market: "GB"
  locale: "en-GB"
  currency: "GBP"

scope:
  include: ["/products/*"]
  exclude: ["/cart/*", "/account/*"]
  notes: "公开商品页；不采账户、订单或个人数据"

discovery:
  strategies: ["sitemap", "category", "pagination"]
  sitemap_urls: ["https://shop.example/sitemap.xml"]
  category_seeds: ["https://shop.example/collections/all"]
  pagination: {type: "next_link", selector: "a[rel=next]"}
  url_identity: "normalized_path"
  product_url_patterns: ["/products/[^/]+$"]

fetch:
  default_engine: "static"
  per_url_type:
    product:
      engine: "browser"
      wait_until: "domcontentloaded"
      wait_selector: "main [data-product]"
  rate_limit: {concurrency: 2, delay_ms: 500}
  retry: {max_attempts: 3, backoff_ms: 1000}
  timeout_ms: 60000

extract:
  fields:
    name: {source: "css", selector: "h1.product-title", required: true}
    price.amount: {source: "json_ld", path: "offers.price", required: true}
    price.currency: {source: "json_ld", path: "offers.priceCurrency", required: true}
    primary_image_url: {source: "css", selector: "img.product-main", attr: "src", required: true}
    description_html: {source: "css", selector: "[data-description]", required: false}
    categories: {source: "breadcrumb", selector: "nav.breadcrumb a"}
    brand: {source: "json_ld", path: "brand.name"}
    options: {source: "css", selector: "[data-option]"}
    availability: {source: "json_ld", path: "offers.availability"}
    source_url: {source: "final_url"}

normalize:
  price: {tax_basis: "EXCLUSIVE", choose: "lowest_public_current", positive_only: true}
  description: {mode: "clean_html", statuses: ["complete", "partial", "fallback", "not_provided", "failed"]}
  options: {exclude_quantity: true, strip_price_delta: true}

validate:
  required_fields: ["name", "price.amount", "price.currency", "primary_image_url", "source_url"]
  assertions:
    - {field: "price.amount", op: ">", value: 0}
    - {selector: "h1.product-title", kind: "content_present"}
  partial_description: "allowed_with_flag"

compatibility:
  os: ["windows", "linux", "wsl2"]
  runtime: "python>=3.11"
  dependencies: []
  network: "public_web; proxy optional"
  secrets: "env:SCRAPE_PROXY (仅名称，不保存值)"

evidence:
  sample_urls: ["https://shop.example/products/example-shirt"]
  expected: {name: "示例运动上衣", price.amount: 24.17, price.currency: "GBP"}
  verified_at: null
  limitations: ["合成示例；未对真实站点取证"]
```

## 版本、导入与复用

`schema_version` 是契约版本，`plan_version` 是站点方案版本，两者不能混用。契约版本变化时，执行端按自己的支持范围决定读取或拒绝；方案版本变化时，旧任务保留旧版本，不因新方案发布而改写历史结果。

导入到另一个兼容环境时，至少检查：

- manifest 的 `schema_version`、`plan_id`、`plan_version` 和目标范围是否可读；
- `kind` 对应的规则或程序入口是否存在，依赖锁、运行时、浏览器和系统版本是否满足；
- 市场、语言、币种和网络出口假设是否仍成立；
- 密钥是否由目标环境注入，而不是随方案携带；
- 导入后是否先做试跑／灰度，再创建新任务。

方案导出不得携带密钥、Cookie、旧批准／进度、任务结果或私有构建会话。兼容环境重跑成功，不等于原环境的历史结果自动有效；旧结果的有效性按原方案版本和原环境解释。

## 验收映射

| 任务或场景 | 应检查 |
| --- | --- |
| D03／A08 | manifest 完整；发现、获取、提取和校验可定位；方案可保存且不依赖私有会话 |
| D04／A09 | 结束构建会话后，执行端只读 manifest 和方案包即可运行；普通批次无逐页 LLM 调用 |
| D05／A10 | 导出／导入后通过兼容检查，必要时先试跑／灰度；不携带密钥、审批或进度 |
| A15 | 方案实质变化时递增 `plan_version`；旧结果标明有效性，修复后重新灰度 |
| D09 | `status: verified` 的方案有样本、期望值、环境、时间和已知限制，不以模型自报代替证据 |

## 不应包含的内容

- 任务进度、任务结果、用户验收结论和审批记录；这些属于任务数据，不属于方案。
- Cookie、密钥、代理密码、登录会话、浏览器 profile 或可复用的 clearance。
- 整页原文、生产数据库、个人数据或未获准保存的站点内容。
- 本机绝对路径、私有临时目录、模型私有推理过程或无法复核的“已验证”声明。
- 把站点差异写成公共引擎特例；站点规则应留在方案或站点适配层。

## 待确认项

- 方案包最终采用 YAML、JSON 还是项目自定义格式；只要满足本契约并能无损映射即可。
- `program`／`hybrid` 方案的入口约定：是相对路径加命令，还是统一的可调用接口；无论哪种，都必须能被执行端在不读取私有会话的情况下启动。
- `verified` 所需的最小证据集是否再按 D09 的实站名单收紧；本文件只规定证据字段，不替代 D09 的站点清单和通过线。
