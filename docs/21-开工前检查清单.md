## 用途与边界

本页把“可以开始实现”拆成可逐项核对的检查项，供项目方、技术负责人和承接方在正式开工前使用。它只汇总 [项目定位](00-项目定位与可行性.md)、[开发任务](04-开发任务与交付.md)、[实施路线](10-实施路线与交接.md)、[交接](15-交接.md)、[规则与运行时](19-采集规则与任务运行时.md)、[环境基线](20-构建环境与依赖基线.md) 和 [网址发现与分页策略](22-网址发现与分页策略.md) 已有的门禁，不新增业务口径；业务规则仍以 01～09 为准，当前状态仍以 [交接与继续](15-交接.md) 和 Git 为准。

只有存在可复核证据时才勾选；未勾选项写负责人、阻塞范围和截止条件。勾选不表示“讨论过”，也不把 Proposed 写成已实现。

## 使用方式

- 开工前或交接会前，按本页逐项核对；状态只写“已满足”“未满足”“不适用”，未满足项写负责人和截止条件。
- 证据位置写链接或命令，不复制证据全文；本页不替代 [交接与继续](15-交接.md) 的当前状态。
- 冲突时以 Git 状态、[交接与继续](15-交接.md) 和基准站实测为准；本页只做门禁汇总。
