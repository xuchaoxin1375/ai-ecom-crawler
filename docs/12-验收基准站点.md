## 用途与边界

本文保存原始需求提供的站点名单，作为**基准集和回归候选**，不是当前可访问、平台识别或采集成功结论。2026-11-19 对其中若干入口做了只读探测（见复核记录），其余地址仍未请求；名单中的备注属于历史线索，使用前必须重新核对。

阶段验收不使用本文逐站判定，而按 [验收场景与比较方法](05-验收场景与比较方法.md) 和 [实施路线与交接](10-实施路线与交接.md) 的 D01 选择代表站。本文的完整名单用于后续广度评估、回归和单站诊断，不能替代阶段验收，也不能把未测站写成通过。

## 使用规则

- 使用前确认访问边界、站点当前结构、目标市场／语言、网络出口和资源上限。
- 每条复核记录日期、环境、出口、市场／语言、实际方法、有效商品数、部分／失败情况、停止原因和证据位置。
- 一次成功不构成长期结论；站点改版、风控和限流都会改变结果，复测条件要写清。
- 失败站、未测站和暂不支持的站保留在名单里；不得删除后提高通过率。
- 同一平台的不同主题不能替代普通 HTML、动态页面、分类分页等路径的代表性。
- 站点名单不是访问授权；robots、服务条款和当地法律边界仍未定，见 `10` 的 A3。

### 美国食品
- https://shop.fooddepot.com/
- https://afsupermarket.com/

#### 2026-11-19 实测

- 两站直连均返回裸 403（`server: awselb/2.0`、`x-cache: Error from cloudfront`），无挑战特征；US 代理出口（PHX）返回 200。属本次出口的地区／IP 拒绝，不是 Cloudflare 挑战，换引擎无效。
- 两站同属 eGrowcery 平台，首屏是 Ember SPA 外壳；`init_config` 给出 API host `production-us-1.noq-servers.net` 和 `apiPath /api/v1/application`，同域 `/api/...` 可能回退成 HTML。
- 商品数据在公开 JSON：`/products/{uuid}` 与 `/products/{uuid}/details`；实测请求带 `Origin`、`Referer`、`x-app-environment`、`x-app-version`，补头后 200，不需登录；缺客户端头时返回 JSON `403 AccessDenied`。
- afsupermarket：sitemap 3 个子图、41,091 条 loc（41,044 唯一），商品 URL 19,287 个；30 个随机商品中名称／正价／可售／主图 30/30，有实质描述（≥80 字符）25/30，5 个原站未提供；配料 19/30、营养 20/30，为独立字段。样本未出现停售，停售语义未实测。
- shop.fooddepot.com：sitemap index 83 个子图，按门店分片；首店商品子图 16,419 个商品 + 15,349 个 CDN 图片，另一店 14,782 个商品。20 个随机商品中名称／正价／可售／主图 20/20，有实质描述 19/20；1 个按磅计价的生鲜无描述。
- 结论：多门店先定门店再取分片，按 UUID 去重，价格和可售状态绑定门店；按重量计价保留 `per lb` 等单位；配料／营养不并入描述。该结果只证明当日样本，不代表全站覆盖。

## 复核记录格式

每次复核至少保留以下字段，便于后续比较和回归：

- 入口与任务范围。
- 复核日期、执行环境、网络出口和市场／语言。
- 路径类型：站点地图、分类分页、动态加载、公开接口或其他。
- 实际方法：HTTP、浏览器、会话复用或人工协助。
- 有效商品数、部分描述数、排除数、失败数和未处理数。
- 停止原因：自然结束、预算、访问受限、质量阻塞、用户取消或其他。
- 证据位置：方案版本、日志摘要、结果文件和必要的截图或样本。

### partsfornissans.com 探测（CF＋分块描述）

2026-11-19 只读探测：robots 返回 200；sitemap 和首页静态请求均为 403 CF。普通 Playwright 有头＋真实 Chrome＋等 45 秒仍为 403；Scrapling 0.5.1 无头＋持久 profile 返回 200；`chrome-late` 有头返回 200。单页约 75–88 秒（Scrapling）和约 40 秒（`chrome-late`）；单会话批量 3 页已取得完整内容（每页等待 5.1–5.6 秒、渲染 20.5–20.8 秒），说明复用会话可行。批量工具曾把残留 CF 脚本误报为 `state=challenge`，实际应按标题和商品内容判定；该判定已在 `resilient-browser-fetch` 修复并补回归测试。

## 2026-11-19 变体与公开 API 实测

对象为 sixmoondesigns.com、javaestate.com 的公开 Shopify `/products.json`，以及 afsupermarket.com、shop.fooddepot.com 的公开 eGrowcery API；只读公开数据，未登录、未下单。

| 观察项 | 结果 | 启示 |
| --- | --- | --- |
| Shopify 变体 | sixmoons 112 个商品中 52 个多变体、28 个价格区间；javaestate 单页 250 个中 27 个多变体、21 个价格区间 | 变体价不一致时，基础价取公开最低变体价，保留区间／起价 |
| 变体可售 | sixmoons 623 个变体中 198 个不可售；javaestate 859 个中 20 个不可售 | 商品可售＝任一公开变体可售；一个变体缺货不等于整品停售 |
| 变体身份 | javaestate 859 个变体中 373 个无 SKU | 缺 SKU 时用商品 ID／handle＋选项值 |
| 缺失字段 | sixmoons 112 个商品中 3 个缺主图、7 个空正文；javaestate 0 个缺主图、0 个空正文 | 缺主图／描述分别标缺失，不用占位或名称补齐 |
| 隐藏／内部说明 | javaestate 捆绑商品正文含 “Not visible on storefront”“Do not change…” | 公开 JSON 可能含商家内部说明；剥离或单独记录，不当作营销正文 |
| API 分页 | `POST /stores/758/products?skip=0&take=5` 返回 5 条，`Meta.Pagination.TotalNumberOfRecords=19,129`；`take=100` 返回 100；`skip=100000` 返回空 | 读分页元数据；空页或 `skip >= total` 停止 |
| sitemap 与 API 差异 | afsupermarket sitemap 19,287 个商品 URL；API total 19,129；差 158 | 两者是不同口径，差异留档，不强行对齐 |
| 公开 JSON 限流 | Shopify `/products.json` 直连 429（`TOO_MANY_REQUESTS`），US 代理 200；`page=2` 可继续 | API 可能单独限流；退避或换出口，不判站点不可采 |
| 跨店身份 | fooddepot 两店 sitemap UUID 交集 0，slug 交集 8,964；同一洗衣液两店 UUID／catalogue ID 不同，`Cd` 解码条码相同 | URL UUID／catalogue ID 可能是门店级；跨店合并优先 UPC／EAN／GTIN／MPN |

补充：eGrowcery 商品 JSON 不带币种，store summary 提供 `Currency: USD`；Shopify 店面提供 `Shopify.currency`（两站均为 USD）。币种取同一店面／市场的全局配置，不凭域名或符号猜。`lastmod` 在两店商品 sitemap 中按商品存在，但价格／库存变化未必更新它，仍按列表层重扫。

结论只证明当日样本，不代表全站；变体、门店和 API 的口径需在任务方案中先定。
