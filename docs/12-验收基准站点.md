## 用途与边界

本文保存原始需求提供的站点名单，作为**基准集和回归候选**，不是当前可访问、平台识别或采集成功结论。2026-11-19 对其中若干入口做了只读探测（见复核记录），其余地址仍未请求；名单中的备注属于历史线索，使用前必须重新核对。

阶段验收不使用本文逐站判定，而按 [验收场景与比较方法](05-验收场景与比较方法.md) 和 [实施路线与交接](10-实施路线与交接.md) 的 D01 选择代表站。本文的完整名单用于后续广度评估、回归和单站诊断，不能替代阶段验收，也不能把未测站写成通过。

2026-11-20 对分类页的 `next_link`／页码机制另做了候选标记，见下文“发现机制候选标记”；它不改变历史初筛结论。

## 使用规则

- 使用前确认访问边界、站点当前结构、目标市场／语言、网络出口和资源上限。
- 每条复核记录日期、环境、出口、市场／语言、实际方法、有效商品数、部分／失败情况、停止原因和证据位置。
- 一次成功不构成长期结论；站点改版、风控和限流都会改变结果，复测条件要写清。
- 失败站、未测站和暂不支持的站保留在名单里；不得删除后提高通过率。
- 同一平台的不同主题不能替代普通 HTML、动态页面、分类分页等路径的代表性。
- 站点名单不是访问授权；robots、服务条款和当地法律边界仍未定，见 `10` 的 A3。
- 原名单优先；覆盖缺口才补外部公开站（官方 showcase、公开 demo、公开搜索），补入时记录来源、URL、日期、出口和证据；`实测` 段是证据台账，不代表原名单未测站已通过。

### 美国食品
- https://shop.fooddepot.com/

#### 2026-11-19 实测

- 两站直连均返回裸 403（`server: awselb/2.0`、`x-cache: Error from cloudfront`），无挑战特征；US 代理出口（PHX）返回 200。属本次出口的地区／IP 拒绝，不是 Cloudflare 挑战，换引擎无效。
- 两站同属 eGrowcery 平台，首屏是 Ember SPA 外壳；`init_config` 给出 API host `production-us-1.noq-servers.net` 和 `apiPath /api/v1/application`，同域 `/api/...` 可能回退成 HTML。
- 商品数据在公开 JSON：`/products/{uuid}` 与 `/products/{uuid}/details`；实测请求带 `Origin`、`Referer`、`x-app-environment`、`x-app-version`，补头后 200，不需登录；缺客户端头时返回 JSON `403 AccessDenied`。
- afsupermarket：sitemap 3 个子图、41,091 条 loc（41,044 唯一），商品 URL 19,287 个；30 个随机商品中名称／正价／可售／主图 30/30，有实质描述（≥80 字符）25/30，5 个原站未提供；配料 19/30、营养 20/30，为独立字段。样本未出现停售，停售语义未实测。
- shop.fooddepot.com：sitemap index 83 个子图，按门店分片；首店商品子图 16,419 个商品 + 15,349 个 CDN 图片，另一店 14,782 个商品。20 个随机商品中名称／正价／可售／主图 20/20，有实质描述 19/20；1 个按磅计价的生鲜无描述。
- 结论：多门店先定门店再取分片，按 UUID 去重，价格和可售状态绑定门店；按重量计价保留 `per lb` 等单位；配料／营养不并入描述。该结果只证明当日样本，不代表全站覆盖。

## 复核记录格式

每次复核至少保留以下字段，便于后续比较和回归：

- 入口与任务范围。
- 复核日期、执行环境、网络出口和市场／语言。
- 路径类型：站点地图、分类分页、动态加载、公开接口或其他。
- 实际方法：HTTP、浏览器、会话复用或人工协助。
- 有效商品数、部分描述数、排除数、失败数和未处理数。
- 停止原因：自然结束、预算、访问受限、质量阻塞、用户取消或其他。
- 证据位置：方案版本、日志摘要、结果文件和必要的截图或样本。

## 2026-11-19 基础字段与描述实测

对象为 repairtoolparts.com 的 30 个随机零件页，只读取公开页面；未做全站覆盖，也不代表其他站点。

| 观察项 | 结果 | 启示 |
| --- | --- | --- |
| Product JSON-LD／名称 | 30/30 | 基础字段大多可直接从结构化数据取得 |
| 价格与币种 | 26/30 有 Offer；4 个只有 `$0.00` 且无 Offer | 零价、无价不是有效商品，保留网址和原因 |

| 描述／品牌 | 30／30 `complete`（384–3,486 字符）；Big Agnes 9、Exped 9、NEMO 6、Therm-a-Rest 6 |
| 变体 | 22 个有 differential 选项（长度／宽度／重量／尺寸／Condition，带 uom）；8 个无可区分选项 |
| JSON-LD 容错 | 1 页评论正文含未转义换行，`json.loads(..., strict=False)` 才能解析 |
| 覆盖 | 分类页标题 144 个商品，处理 30 个；`PARTIAL`，不写成分类全量 |

结论：挑战站不是不可采，但默认无头栈不可采；有头晚接入 + 低批大小可行。单页晚接入约 32s，批量摊薄启动成本；**推荐 3–5 个标签/批**，pilot 的 10 标签批只作为偏差证据。商品 JSON-LD 出现即读，不等图片／广告／networkidle。证据见 `experiments/d01/campsaver/`。

### PrestaShop 颜色家族归并（familidoo Lidoo One）

2026-11-19 取 familidoo.fr 的 4 个颜色页（Noire／Grise／Rouge／Bleue，商品 ID 183～186），静态 HTTP 直连；只读公开页面，未登录、未下单。

| 观察项 | 结果 |
| --- | --- |
| 商品页 | 273–306 KB；1.1–4.7s；0 JSON-LD |
| URL／canonical | 4 个独立商品 URL；均自指 canonical；无组合参数 |
| 标题 | `Poussette compacte Lidoo One` + 颜色；共用型号 |
| SKU | `H1E-Black`／`H1E-Grey`／`H1E-Red`／`H1E-Blue` |
| GTIN | `meta itemprop="GTIN13"`：`4712928373475`／`…3499`／`…3468`／`…3482` |
| 价格／币种 | 4 页均 `89,00 €`；`product:price:amount=89`、`EUR`；无划线价 |
| 状态／库存 | 4 页均 En stock；数量 8／26／34／24 |
| 描述 | 4 页均 1,193 字，仅颜色词不同；Grise 页描述误写 “Black” |
| 变体控件 | 无 select／radio；`product-variants` 为空；颜色页互相链接 |
| 交叉链接 | 每页链接其余 3 色，并有各自加购入口 |

结论：

- 按“变体归并”的商品单位，这是一个商品（Lidoo One）的 4 个颜色变体，不应算 4 个商品；按 SKU 级导出则保留 4 行，但必须在计数口径中声明。
- 变体键用 SKU 或 GTIN；family 键用“型号＋颜色”归一化后的商品名，不按 canonical 合并（4 页都自指），也不只按标题去重（颜色在标题里）。
- 颜色以标题、SKU、GTIN 为准，不用描述推断：Grise 页描述写成 “Black”，说明描述可能复制错误。
- PrestaShop 把颜色做成独立商品而非组合时，单页没有 selects 不代表无变体；跨页交叉链接是发现同族的直接线索。

### 自定义站微数据提取（fr.lennylamb.com）

2026-11-19 按分诊顺序读取 robots、sitemap、分类页和 3 个商品样本；直连，Python requests 2.33.1，Chrome 131 UA，目标请求 13 次（含 4 次重复复核和 1 次 404 别名测试），未登录、未下单。

| 观察项 | 结果 |
| --- | --- |
| robots／sitemap | `Crawl-delay: 1`；sitemap index 含 `products.xml`；`products.xml` 902 条（895 个 `web_page`、7 个 `ware`），混有编辑页和政策页，不能当商品数 |
| 首页／分类 | 此前首页分诊记 5 个商品形链接；分类页 `shop/by/erp_product_type/lenny_upgrade_pro` 给出 24 个 `a.product_box`，每盒有标题、图片、价格并指向 `web_page/<id>`，页面本身无加购 |
| 商品页 | `web_page/44091` 210KB、`web_page/44225` 199KB、`ware/158` 155KB；均 0 JSON-LD；canonical 自指 |
| 结构化数据 | `div[itemtype="http://schema.org/Product"]` 微数据：`name`、`sku`、`mpn`、`brand`、`price`、`priceCurrency`、`availability`、`url`、`description`、`image`、`weight`、`priceValidUntil` |
| 价格／币种 | 44091：197.88 EUR；44225：176.48 EUR；158：66.85 EUR；microdata 与 DOM 一致，两个 carrier 页与分类盒一致；无 `product:price:amount` |
| 状态 | 3 页均 `availability=InStock`；缺货模板未测 |
| 描述 | `itemprop=description` 清洗后 2,437 字（44091／44225 完全相同）和 1,255 字（158）；含安全标准、功能、纤维说明，模板化，非变体特有正文；需先剔除内联 `<style>` |
| 变体 | 同型号 LennyUpGrade PRO 的 24 个面料／颜色各为独立 `web_page`，无 select／radio；商品页有兄弟变体链接与 `?fabric=` 筛选参数 |
| 身份 | `web_page/<id>` 是公开商品页；`mpn` 是内部购物车／ERP id（44091 为 41295），`/ware/41295` 返回 404，不能由 mpn 拼 URL；`ware/<id>` 是部分商品的另一模板 |

结论：

- 无 JSON-LD 的站仍可能有 Product 微数据；先查 `[itemtype*="Product"]` 与 `[itemprop]`，再退回 DOM。
- sitemap 的 `web_page` 路由混编辑页，不能按路径或数量判商品；分类页 `product_box` 是更可靠的发现入口。
- 同一型号的 24 个面料／颜色是独立商品页，属一个变体家族；按标题／SKU 归并，`?fabric=` 是筛选参数，不是新商品。
- 描述是跨变体共享的模板长文；可记完整但注明非变体特有，不能把模板重复当成 24 份独立正文。
- `mpn` 可能只是购物车／ERP 标识；公开 URL 用页面自身 canonical／microdata `url`，不要用 mpn 构造。

### Shopify 模型店商品页（rcteam.com）

2026-11-19 按分诊顺序读取 robots、sitemap、`products.json` 与 4 个商品页；直连，Python requests 2.33.1，Chrome 131 UA，目标请求 10 次（其中 4 次 `products.json` 复核），未登录、未下单。站点语言／市场为 FR／EUR，不是 DE。

| 观察项 | 结果 |
| --- | --- |
| robots／sitemap | robots 允许商品页；sitemap index 257 条，含多个 products 子图 |
| 列表 JSON | `/products.json?limit=250&page=1` 200／1.66MB；250 商品、304 变体、32 个多变体、45 个不可售变体；价格 3.50–1075.99 |
| 商品页 | 4 个样本 200／约 1.0MB／0.54–1.20s；`Shopify.currency` active EUR |
| JSON-LD | 主题 Product 块有 `@id`／productID、name、sku、brand、image、description、offers；部分页另有 `y-rich-snippet-script` Product 块，带 aggregateRating |
| 价格／币种 | meta `product:price:amount` 与主题 JSON-LD 一致：49.90／8.90／199.90／1075.99 EUR；页面另有 149€ 免邮门槛文本，不能当主价 |
| 状态 | 单变体 InStock；多变体 AggregateOffer 只有 low／high／offerCount、无 availability；全缺货商品的主题块 OutOfStock、app 块 InStock 冲突，`products.json` 与页面 `Indisponible` 支持主题块 |
| 描述 | JSON-LD description 与 `span.description` 文本完全一致（660／1,181／3,970／6,804 字）；宽泛 `.rte` 只取到部分区块 |
| 变体 | 多变体页有 1 个 select + 6 个 radio；Noir 的 select option `disabled`、`products.json` `available=false`；radio 本身没有 disabled |

结论：

- Shopify JSON-LD 可能重复；主题块（带 `@id`／productID）优先，`y-rich-snippet-script` 这类 app 块可能给出过期库存，冲突时以 variants／`products.json` 和页面购买控件为准。
- 多属性 Shopify 商品的 AggregateOffer 不一定有 availability；按 variants 的 `available` 或 select option 的 `disabled` 判变体状态，不能只看父级 JSON-LD。
- 完整描述用 `span.description` 或 JSON-LD description；宽泛 `.rte` 会漏掉后续区块。
- 主价用 meta／主题 JSON-LD／`price-list`；页面上的 149€ 免邮门槛不是商品价。
- `products.json` 可一次拿到 250 商品与变体库存，适合列表层发现；商品页只补描述和结构化字段。

其余德国模型站复用 2026-11-19 分类，本次未重试：`scheufele-modellbau.de` 需会话／JS；`speedshop24.de` 超时；`modellparadies.com` 444；`derkum-modellbau.com` 403 Cloudflare。
