## 用途与边界

本页是[React v2 前端改进待办](frontend-backlog.md)推广计划阶段 2 的设计草案：在不改后端接口、状态契约、已分享深链接、React 外壳和视觉令牌的前提下，重组站点详情。

默认先显示当前采集和结果，任务历史、规则版本、构建和资料移到明确入口；构建等待审批时，请求和处理后的影响仍在首屏可见。任务详情、构建详情和全局导航不在本阶段。

本页的视图名称、标签分组和 CSV／明细去向已经项目方确认按推荐方案执行，见“已确认决策”。实现记录和未覆盖项见文末。

## 首屏结构与 HTML 草稿

线框主稿是可浏览的静态 HTML：`experiments/d08/site-detail-prototype/index.html`。打开方式、状态切换和覆盖点见该目录 `README.md`；1280 和 390 截图在仓库外 `workbench/site-detail-prototype-20261125/`。下方文字只固定内容顺序和验收口径，不替代实际原稿。

| 顺序 | 内容 | 桌面 | 窄屏 |
| --- | --- | --- | --- |
| 1 | 返回、站点标识、可采／任务／构建状态 | 同一行，标题左、状态右 | 标题和状态换行，返回在上 |
| 2 | URL、备注、状态句、更新、规则 | 标题下方一行或多行 | 备注最多两行，其余换行 |
| 3 | 主操作、更多、刷新 | 页头右侧同一行 | 按钮换行，主操作仍先出现 |
| 4 | 构建等待审批 | 摘要之前，整行 | 摘要之前，整行 |
| 5 | 紧凑摘要：任务、有效／失败、覆盖、质量异常 | 四列 | 两列，360 像素以下单列 |
| 6 | 视图切换：当前采集、任务历史、规则与构建、站点资料 | 标签栏 | 标签横向滚动或单选 |
| 7 | 当前采集内容 | 任务摘要、商品预览、质量异常、原始数据入口 | 同顺序，商品预览单列 |

当前采集的任务摘要只保留停止原因、更新、排除和结果；状态、有效／失败、覆盖和质量异常已经在上方摘要里，不重复铺两层事实。窄屏隐藏任务摘要的第二层事实，优先露出商品预览第一行。

## 操作位置

| 位置 | 放什么 | 约束 |
| --- | --- | --- |
| 页头 | 当前对象、状态、一个随状态变化的主操作 | 主操作与状态表一致；同一后果不在页头和其他区块重复常驻 |
| 「更多」 | 导出（主操作不是导出时）、取消任务／构建、回批次复跑等低频操作 | 取消保留二次确认；导出只出现一次 |
| 当前采集 | 任务摘要、商品预览、质量异常、结果刷新 | 任务控制不在任务卡片内重复；任务卡片只保留「打开任务详情」 |
| 任务历史 | 最近任务和「全部任务」 | 不再常驻右侧；进入视图后加载 |
| 规则与构建 | 构建状态、构建详情入口、规则版本、候选激活／回滚、修复入口 | 审批不放在此视图，始终在首屏 |
| 站点资料 | 批次、国家／市场、语言、品类、规则、构建 ID、任务 ID、路径等技术事实 | 默认折叠或独立视图，不与结果争首屏 |

导出范围沿用现有文案：站点页只导出当前任务，不包含该站点的其他历史任务；任务运行中为部分结果。页头主操作是导出时只保留该入口；否则导出进入「更多」。

## 状态表

| 站点／任务／构建状态 | 首屏主区 | 页头主操作 | 更多与辅助入口 |
| --- | --- | --- | --- |
| 无效或重复 | 原因说明与返回批次 | 无；回批次详情 | 无采集动作 |
| 待接入，构建可用 | 构建面板与启动说明 | 启动构建 | 刷新；站点资料 |
| 待接入，构建不可用或配置读取失败 | 阻断说明与重试（读取失败时） | 禁用并说明 | 同左；不出现可点击的构建入口 |
| 构建排队／运行／暂停／验证中／取消中 | 构建状态与审批（如有） | 暂停／继续／取消排队 | 构建详情；刷新 |
| 构建成功，站点未启动 | 空结果状态与启动说明 | 启动采集 | 规则与构建；站点资料 |
| 最近构建失败或中断 | 错误／恢复说明 | 重新构建（可用时） | 构建详情；继续原会话在构建详情 |
| 可采，未创建任务 | 空结果状态 | 启动采集 | 规则与构建；站点资料 |
| 任务排队或草稿 | 任务摘要，尚无结果 | 取消任务 | 打开任务详情 |
| 任务运行或暂停中 | 当前结果优先 | 暂停任务／继续任务 | 导出（更多）、取消（更多）、任务详情 |
| 任务正在取消 | 状态说明，保留已产生结果 | 无 | 导出（更多）、任务详情 |
| 任务完成 | 结果 | 导出当前任务 ZIP | 回批次复跑；任务详情 |
| 任务部分完成 | 结果与质量异常 | 修复规则（可用时）；否则回批次复跑 | 导出（更多）、任务详情、候选规则入口 |
| 任务已取消 | 已有结果或空状态 | 回批次复跑 | 导出（更多）、任务详情 |
| 构建服务读取失败 | 保持现有结果 | 构建／修复入口禁用 | 重试读取配置；其他任务操作不受影响 |

构建等待审批时，审批卡始终在摘要和视图切换之前；批准、拒绝和提交失败重试都不要求先打开「规则与构建」。

## 视图与内容去向

| 视图（候选名） | 内容 | 来源 |
| --- | --- | --- |
| 当前采集 | 任务摘要、商品预览、质量异常、原始数据入口 | 现有 `ProductPreviewSection`、`QualityExceptionsSection`、`TaskCsvPreview`、`TaskItemsSection` |
| 任务历史 | 最近任务、全部任务链接 | 现有站点任务历史查询 |
| 规则与构建 | 构建面板、构建详情入口、规则版本、候选激活／回滚 | 现有 `BuildPanel`、规则版本卡、`RuleEvidence` |
| 站点资料 | 批次、市场、规则路径、任务／构建 ID、创建与更新时间 | 现有站点事实与技术详情 |

待确认：CSV 预览和任务明细是留在「当前采集」的折叠区，还是只保留在任务详情并从站点页链接过去。前者保留站点级自查，后者减少重复和长页。

## 深链接映射

- 现有 `/batches/{batchId}/sites/{siteKey}` 保持不变；批次清单下钻和已分享链接不受影响。
- 视图用查询参数表达，候选为 `?view=current|history|rules|info`，默认 `current` 省略；无效值回到 `current` 并用 `replace` 修正。
- 同一页面切换视图用 `replace`，不把每次切换写入浏览器历史；浏览器后退仍回到进入站点前的批次清单。
- 显式「返回批次」继续使用现有 `siteListReturn`，恢复搜索、筛选、滚动位置和行焦点；无来源深链接回到默认批次清单。
- 任务链接继续使用 `/tasks/{taskId}`，构建链接继续使用 `/builds/{buildId}`；返回站点时默认打开当前采集，除非浏览器后退恢复了原视图。
- 不新增全局路由，不改变批次、任务和构建路由。

## 组件与数据复用

- 复用现有 React 外壳、颜色令牌、`DataTable`、`Badge`、`Button`、`DropdownMenu`、`InlineNotice` 和确认弹窗。
- 复用 `BuildApprovals`、`BuildPanel`、`ProductPreviewSection`、`QualityExceptionsSection`、`TaskCsvPreview`、`TaskItemsSection`、`RuleEvidence` 和任务历史查询。
- 不新增后端接口，不改任务／构建状态和计数契约；视图切换只影响前端展示。
- 站点页的状态判断继续使用 `siteNextStep`、`buildServiceBlockReason`、`siteHasActiveWork` 和候选激活阻断判据。

## 响应式与可访问性

- 1280 × 900 和 390 × 900 为首要对照，768 和 320 为交付前检查。
- 390 首屏至少看到站点名、状态、主操作和当前采集的第一块内容；任务存在时优先露出商品预览第一行。
- 视图切换支持键盘；焦点不因切换丢失；关闭弹窗后回到触发按钮。
- 表格和长文本只在自身容器内滚动，不产生页面级横向溢出；行菜单在横滚后仍可操作。
- 构建审批卡不使用折叠或仅图标入口；拒绝和批准都用文字按钮。

## 验收清单

- 从筛选过的批次清单下钻，分别走待接入、可采未启动、执行中和已结束四条路径，再显式返回和浏览器后退，原搜索、筛选、滚动和焦点都能恢复。
- 任务历史、规则版本、候选激活／回滚和修复入口仍可到达，未因重组丢失。
- 当前任务导出只有一个常驻入口，文案能区分部分结果和完整结果；不包含历史任务。
- 候选规则验证不足时仍能看到阻断理由和证据入口，不出现可直接激活的误导按钮。
- 构建等待审批时，首屏能看到请求和处理后的影响；批准、拒绝和提交失败重试可用。
- 1280、768、390、320 无页面级横向溢出；首屏出现关键数据或审批；键盘切换视图和返回焦点正常；桌面 axe 违规为零。
- 现有后端测试、前端测试、lint、typecheck、format、build 通过；真实账本只读走查，写操作在隔离账本验证。

## 已确认决策（2026-11-25）

项目方确认 D1–D7 全部按推荐方案执行：

| 编号 | 决策 | 采用方案 | 备选与代价 |
| --- | --- | --- | --- |
| D1 | 视图组织方式 | 页内视图切换，`view` 写入查询参数 | 全部折叠区：实现简单，但首屏仍可能堆叠；独立子路由：链接更清楚，但改动现有 URL 结构 |
| D2 | CSV 预览和任务明细去向 | 移到任务详情，站点页只留结果预览、质量异常和入口链接 | 留在当前采集的折叠区：站点级自查方便，但重复任务详情内容 |
| D3 | 构建与规则是否合并 | 合并为「规则与构建」，运行中的构建在首屏加状态条 | 独立「构建」视图：入口更直白，但增加一个低频标签 |
| D4 | 任务历史位置 | 独立视图，保留「全部任务」链接 | 当前采集底部折叠：少一次切换，但长页重新出现 |
| D5 | 站点资料位置 | 独立视图，技术信息合并进去 | 页尾折叠：实现简单，但窄屏首屏不受影响、深链无法直达 |
| D6 | 导出入口 | 任务完成时页头主操作；其他状态放「更多」 | 固定侧栏入口：可见性高，但与批次试点唯一入口原则冲突 |
| D7 | 无任务但构建运行中的默认视图 | 当前采集显示构建状态条和审批，主操作指向构建 | 自动切到「规则与构建」：更聚焦，但用户先失去站点当前状态 |

## 实施切分

1. 先搭页头、紧凑摘要、视图切换和唯一导出入口，保持现有查询和 URL 可用。
2. 把任务结果留在当前采集，把历史、规则／构建和资料移入各自视图；构建审批固定在首屏。
3. 按状态表接主操作与「更多」，处理构建不可用、读取失败、候选阻断和取消确认。
4. 补组件测试、浏览器走查、1280／390／768／320 截图和 axe；通过后再推广到任务详情。

## 实施记录与验收范围

2026-11-25 已按 D1–D7 实现：

- 站点页使用四个视图和 `?view=` 查询参数；窄屏切换改用单选控件，桌面保留标签栏和方向键导航。
- 当前采集先显示任务摘要、商品预览和质量异常；CSV 与任务明细只保留任务详情入口。
- 「规则与构建」合并构建面板、规则版本和候选激活／回滚；构建审批仍在摘要之前，有活动构建或中断构建时当前采集显示紧凑状态条。
- 页头只保留一个随状态变化的主操作；导出只在主操作或「更多」出现一次；任务卡片不再重复暂停／继续／取消。
- 验证：前端 94 项测试、lint、typecheck、format、build 通过；Chromium 冒烟 9.84 秒覆盖站点视图、单一导出、CSV 入口和 390 像素商品预览；1280 axe 0 violations，方向键可切换标签；1280／768／390／320 无页面级横向溢出。截图在仓库外 `workbench/site-detail-stage2-20261125/`。
- 未覆盖：未在浏览器重复下载站点导出，未走查真实运行中任务的暂停／取消写入；未重测 Firefox／WebKit、读屏和真实触屏。任务详情和构建详情仍待后续阶段。
