## 线索的用途

以下来自原采集Skill的参考材料，属于**待验证的查找线索**，不保证某个网站或版本一定存在这些形状。平台识别用于降低分析成本，实际响应和字段证据决定方案。团队不需要为这张表逐平台预写固定解析器。

| 平台线索 | 可先查看的公开位置 | 风险 |
| --- | --- | --- |
| Shopify资源或主题信号 | sitemap、商品／集合页、实际可用的商品JSON或公开Feed | 多语言市场、公开接口不可用、币种缺失 |
| WooCommerce资源与Product标记 | 分类、分页、sitemap及可验证公开商品数据 | 插件和主题改写页面与目录 |
| Magento／Adobe Commerce资源 | 分类网格、规范链接、sitemap | 前端与接口形状差异，不猜认证请求 |
| BigCommerce资源 | 分类卡片、规范链接、sitemap | 部分接口需要认证，不能把公开线索当令牌许可 |
| Shopware或Salesforce Commerce Cloud线索 | 商品列表、公开搜索／分类及分页 | 区域、会话和主题差异 |
| 未知自建站 | 主商品DOM、结构化标记、链接簇和公开导航 | 不套其他平台路径模板 |

## 字段来源参考

| 字段 | 可选来源 | 核对点 |
| --- | --- | --- |
| 名称 | 唯一商品标题、Product数据、商品Meta | SEO整页标题和店铺名混入 |
| 价格 | 当前商品报价、变体数据、购买区 | 现价／原价／差价、币种、税价选择和数值排序 |
| 币种 | 同报价明确代码或有绑定的市场数据 | 货币符号与地区不是唯一依据 |
| 主图 | 商品结构化图片、主图库、公开商品数据 | 占位图、相对地址和推荐图 |
| 描述 | 产品正文、分散规格、含HTML的商品字段 | JSON-LD／Meta常只是摘要，不能覆盖已有完整正文 |
| 品牌 | 明确brand值、品牌区块或商品绑定数据 | 店名／vendor字段不能不经语义核对就当品牌 |
| 选项 | 控件、嵌入JSON、当前商品公开选项 | 数量与套餐差价排除，不枚举组合 |

来源不是固定优先级，各字段可以不同。使用正则读取稳定脚本标量时须锚定当前商品上下文；整页HTML结构和描述清洗仍采用解析器。

## Shopify形状示例

若真实公开响应含`product`对象，`product.title`、`product.body_html`、`product.image.src`／`product.images`、`product.options`和`product.variants`可以作为字段线索。具体路径按原件核对，不保证所有公开端点相同。

`variants`报价按本文档口径计算最低当前价，不能取首个可售变体近似。`body_html`保留清洗HTML；默认`Title=Default Title`不是必须制造的真实选项。数据缺币种时不能仅凭美元符号补USD，必须另有同报价依据。

公开目录不可用可回到sitemap／HTML，不猜管理员或认证接口。公开接口可用、平台猜对、数据质量通过和目录完成是不同事实。
