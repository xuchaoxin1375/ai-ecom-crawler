## 判断入口和商品

优先复用已有真实链接、sitemap、公开目录、语言及页面证据，不重复请求已经足以支持判断的网址。平台特征用来缩小搜索范围，不能直接决定页面类型或宣称目录完整。

| 信号 | 应如何理解 |
| --- | --- |
| 主体Product数据、商品标题与价格、购买／数量控件 | 正向商品证据，仍核归属 |
| 商品标题但没有价格，同时有购买按钮或缺货状态 | 保留待判断；不能直接当目录或删除 |
| BreadcrumbList／WebPage／CollectionPage／ItemList等附属标记 | 单独不足以否定商品身份 |
| 浅层数字路径、未知后缀 | 仅路径线索，不因不认识而排除 |
| 型号零件列表，含多个配件价格和按钮 | 通常为导航入口；先取行内字段，字段不足再取零件详情，不聚成一个商品 |

大型混合sitemap按目录前缀、疑似商品形态和主要区段分层查看，不能只看开头几条或某个分类就否定全站。产品可能集中在少数区段，小规模整体均匀采样也可能漏检。

## 入口阶梯与无 XML sitemap

按证据顺序尝试，不把 XML sitemap 当唯一入口：

| 顺序 | 入口 | 注意 |
| --- | --- | --- |
| 1 | XML sitemap／公开 feed | 检查索引、分片和声明位置；robots 没有声明不等于不存在 |
| 2 | HTML sitemap／站点索引 | 路径名不一定叫 sitemap；不要请求 robots 明确禁止的路径 |
| 3 | 分类／全量列表页 | 一次返回几百个型号或商品的 `-list`、`all` 页；确认是否真全量 |
| 4 | 分页／加载更多／游标 | 按实际机制处理，不假定统一 `?page=` |
| 5 | 站内搜索／公开查询接口 | 只作定点查找或有界补充，不当全量目录 |

没有 XML sitemap 只影响发现路径，不单独构成“不可采”。HTML 索引、分类全量列表和公开 feed 可以组合使用；记录实际入口、覆盖范围和停止依据。公开 JSON、XML feed 和搜索接口要先确认是否需要认证、是否只覆盖子集、`total` 是否只是当前关键词的结果数。

### sitemap 变体与解析

- sitemap 可能是 `urlset`、`sitemapindex`、命名子图或 `.xml.gz`；先看状态、`content-type` 和文件头，再决定解析方式。
- 解析失败不等于“没有 sitemap”：可能是 403 的 HTML、挑战页、编码问题或 gzip 未解压。记录状态、内容类型、字节数和首字节。
- sitemap index 可能有上百个子图；只取前几个时必须标“部分枚举”，不能把子图计数当全站总量。
- 多门店／多市场 index：子图常按门店或市场分片，商品 URL 带门店前缀；先确定目标门店再取对应子图，同一商品跨门店按业务键合并，价格和库存绑定门店。
- 公开 JSON 目录：先读 `skip`／`take`、`page`／`limit`、`total` 等分页元数据；空页或 `skip ≥ total` 停止；sitemap 与 API total 是不同口径，差异留档。
- 命名子图本身是发现地图：按名称识别 `product.entity`、`category.product-list`、`variant`、`review`、`qna` 等类型，优先取商品实体图。
- 无 sitemap 且带 `Crawl-delay` 时，HTML 索引、分类页和公开目录是主路径；商品与分类 URL 可能共用路径形态，必须按内容判型。
- 没有 Product JSON-LD 仍可能是商品页；用标题、价格、购买区、重复卡片和父子关系综合判断。

更多站点（Shopify 大图站、大型 sitemap index、`.gz`、无 sitemap + Crawl-delay、挑战页）见[验收基准站点](../12-验收基准站点.md)的扩展探测记录。

## 判型证据与多入口

发现阶段先扩大候选，不按“看起来不是商品”提前删除。导航页、列表页和搜索结果即使不是商品，也可能是通向商品的路径。

- URL 形态只是假设：`/products/`、数字 ID、浅层路径、`.html` 和无扩展名都可能是商品；先抽样 1–3 个页面，核对标题、Product 结构化数据、价格／购买区和主内容，再写判型规则。
- sitemap 条目不等于商品：sitemap 可能混合分类、商品、政策和图片；用页面内容或结构化数据确认，不只看 `<loc>`。带图片和高 priority 的条目是线索，不是结论。
- 多入口要记录贡献和重叠：XML sitemap、HTML 索引、分类、分页、搜索分别新增了多少实体 URL；用并集扩大召回，用重叠判断哪个入口更完整。
- 发现预算按产出率分配：每 100 个请求新增多少唯一实体 URL；高扇出导航优先，低产出的重复入口降级。
- 同一 URL 可能因客户端不同返回 200／406／403：先比较一个变量（UA、headers、HTTP 客户端），区分网络、权限、挑战和客户端差异；不把一次 406 当站点不可采，也不靠伪装绕过访问控制。
- robots 按 UA 组匹配：`Crawl-delay` 可能只属于特定 user-agent 组；按实际 UA 组判断，不确定时取更保守值。无 `Crawl-delay` 不是高速许可。

## 入口重叠与重复率

覆盖率和召回率是进阶审计项；结构清晰、入口和身份稳定时，优先路径完整性、停止条件和样本代表性，不默认计算全站百分比。

发现阶段至少记录：

| 指标 | 口径 |
| --- | --- |
| 入口产出率 | 唯一实体 URL ÷ 已抓页面数 × 100 |
| 实体占比 | 实体候选 ÷ 已发现 URL |
| 重复率 | 1 − 唯一目标 URL ÷ 目标 URL 出现次数 |
| 入口重叠 | 两个入口交集的唯一实体数 ÷ 并集唯一实体数 |
| 部分枚举 | 已取子图数 ÷ 子图总数 |

`召回率`只有在分母来源、范围和观测时间明确时才能写；否则只写阶段覆盖或入口并集。只保存唯一 URL 集合无法计算重复率，需要保留链接出现或 `occurrences`。

抽样要分层，不能取发现顺序前 N 个：同一批 `-parts` 形状候选，按发现顺序前 400 个只有 2 个是含零件行的型号页；从剩余候选中随机抽 100 个有 91 个型号页；随机 300 个型号页得到 12,384 次零件链接出现、5,113 个唯一零件，重复率 58.7%，平均每页 41.3 条零件链接。URL 规则可能整体精度不低，但发现顺序会先遇到品牌／分类页。

一次入口重叠实测：同一多层目录的 HTML `/site-map` 给出 558 个唯一型号；三个高扇出分类页分别给出 855、456、387 个唯一型号，但每个分类页的型号链接都出现两次（重复率 50%）。两组入口并集 2,256 个型号，交集为 0。结论是**多入口互补，且必须先做 URL 去重**；只抓一个入口会漏掉另一组。

## 实体层级与去重

目录型商品站常见“品牌 → 分类 → 型号／系列 → 零件／单品 → 文档／图纸”多层结构。发现阶段先写清：

- 业务计数单位是什么：单品、变体、型号、零件、套装还是文档。
- 跨页面稳定的身份键是什么：SKU、零件号、型号＋变体、canonical URL；URL 只是定位，不是身份。
- 父子关系如何记录：型号页的零件行属于哪个型号；同一零件出现在多个型号上下文时，按业务键合并。
- 列表页是导航还是商品：一行多价格、多按钮的型号零件表通常是入口，不聚成一个商品；具体按数据标准判断。
- 多门店／多市场：URL UUID、slug、catalogue ID 可能是门店级或分组级；先用两店样本验证，优先 UPC／EAN／GTIN／MPN。

没有 canonical 或 URL 形态不一致（`.html`、大小写、尾斜杠、父级前缀）时，不能只靠 URL 规范化去重；用业务键和样本核对。型号页的多行零件表、零件页的兼容型号列表分别记录关系，不互相替代。

## 分页与加载

1. 记录实际目录来源、商品链接身份、分页／游标和停止依据。
2. 普通下一页、数字页码、偏移、加载按钮和滚动按实际页面机制处理，不假定统一形式。
3. 可以使用浏览器观察公开请求，再选可复现请求或DOM方案；有请求体、复杂状态或需要交互时，不凭猜测编一个简单GET接口。
4. 列表页没有下一页但成员很多时，用成员数、重复集合和分类覆盖判断是否完整；不要凭“没有分页”断定不完整，也不要凭页面很大就假定全量。
5. 持久保存去重成员、待访问分支及进度；循环和重复不构成新商品。
6. 继续明确后续，不因开发样本够或批次窗口结束就宣布发现完成。

多语言优先入口及商品网址中明显的语言／国家分支，例如`/de/products/`、`/en-gb/products/`。模糊或冲突保留并说明，不要求证明全部翻译等价；语言路径不能证明市场或币种。

## 证据与交接

发现输出至少包括有效导航入口、商品候选、待处理分支、发现动作及实际停止原因。候选数量、不同商品候选数、完成工作数、访问导航数和剩余待访问量分开。

流式发现和商品处理并行时可短暂积压，先核待处理与在途事实，再判断丢失。输入样本分类矛盾、缺代理依赖等属于输入／环境问题，先修相应层，不换模型重复同一候选。

基础可用不强求零漏、可信总量或自动对账。人工认可覆盖够用，记录为业务验收，同时保留真实范围和剩余工作。
