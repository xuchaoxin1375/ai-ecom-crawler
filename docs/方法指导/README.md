## 使用方式

这里保存从实际采集Skill提炼的**普通方法文档**，既可供开发者阅读，也可由Agent按需加载。不要求安装为Skill，不复制旧任务合同、仓库路径、固定工具权限或历史审批顺序。

| 指导 | 使用时机 |
| --- | --- |
| [方案开发与字段选源](01-方案开发与字段选源.md) | 分析新站、试跑、字段漏采或模板变化；基础／进阶字段、描述状态与截图核验 |
| [网址发现与分页](02-网址发现与分页.md) | 站点地图变体、HTML 索引、分类／全量列表、语言分支、分页、判型证据、多入口产出率/重叠/重复率、部分枚举或实体层级 |
| [访问恢复与诊断](03-访问恢复与诊断.md) | 403／429、挑战、空壳或不同客户端行为不一致 |
| [浏览器与会话复用](04-浏览器与会话复用.md) | 动态渲染、共享会话、检测维度、资源回收 |
| [任务验收与效率](05-任务验收与效率.md) | 真实提交、阶段观测、采集深度与规模预算、基础字段验收、统计、效率比较和证据汇总 |
| [平台与字段线索](06-平台与字段线索.md) | 降低首次分析成本，作为待验证线索使用 |
| [分阶段策略与效率](07-分阶段策略与效率.md) | 按分诊、发现、获取、提取、校验、效率/停止复盘基准站，制定请求/字节/墙钟预算 |

业务口径以包内[数据标准](../02-数据标准与导出.md)为准；方法不能把未确认的来源当事实，也不自行扩大采集范围或保存政策。开放浏览器实现是上游参考，本目录不附源码副本，也不是这些文档的运行依赖。
