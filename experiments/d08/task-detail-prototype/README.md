# 任务详情阶段 3 原型（2026-11-25）

这是[任务详情改版设计](../../../docs/40-任务详情改版设计.md)的静态 HTML 草稿，用于评审结果优先、视图收纳、状态切换和导出入口。它不是生产页面，没有接入后端。

## 打开方式

在 `experiments/d08` 目录启动静态服务器（需要同时加载同目录的站点原型样式）：

```powershell
python -m http.server 8782
```

然后打开：

```text
http://127.0.0.1:8782/task-detail-prototype/#/task?state=product-done&view=results
```

不要直接用 `file://` 打开；ES modules 和相对样式会被浏览器拦截。

## 原型控制

页面顶部的虚线区域只用于评审，不属于产品界面：

- **页面状态**：商品完成、商品运行中、商品部分完成、商品空结果、网址任务完成、旧规则结果、读取失败。
- **视图**：结果、质量与验收、数据明细、运行明细。
- **`chrome=0`**：隐藏原型控制区，便于按生产首屏截图。

主要状态和视图也会写入 hash 查询参数，便于直接分享某一屏。

## 覆盖的评审点

- 商品任务先见商品预览，网址任务先见网址明细；结果验收、CSV、全部明细和任务事实各自收纳。
- 页头只保留一个随状态变化的主操作；终态导出在页头，运行中导出在「更多」。
- 结果为空、部分完成、旧规则和读取失败都在结果区说明，不把空状态放到侧栏底部。
- 质量与验收包含反馈表单和质量异常；数据明细包含 CSV 和全部明细；运行明细包含任务事实和内容完整度。
- 窄屏用单选控件切换视图，商品预览单列，表格在容器内滚动。

## 明确不做

- 不连接真实 API、SQLite、任务 worker、SSE 或反馈服务。
- 不执行真实导出、暂停、取消、归档或反馈提交；相关按钮只给 mock 反馈。
- 不代表最终视图名称、质量反馈分组和 CSV 去向；这些在 `docs/40` 的待确认决策里。
- 不覆盖深色主题、读屏、真实触屏或完整四引擎浏览器矩阵。

## 文件

- `index.html`：外壳、侧栏、顶栏和挂载点。
- `styles.css`：导入站点原型的共享样式，并补任务详情专用块。
- `app.js`：mock 数据、状态／视图切换、菜单、反馈表单和键盘 tab 导航。
