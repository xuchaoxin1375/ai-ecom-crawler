# 站点详情阶段 2 原型（2026-11-25）

这是[站点详情改版设计](../../../docs/39-站点详情改版设计.md)的静态 HTML 草稿，用于评审首屏顺序、操作位置、状态切换和视图去向。它不是生产页面，没有接入后端。

## 打开方式

在本目录启动静态服务器：

```powershell
python -m http.server 8781
```

然后打开：

```text
http://127.0.0.1:8781/#/site?state=done&view=current
```

不要直接用 `file://` 打开；ES modules 可能被浏览器拦截。

## 原型控制

页面顶部的虚线区域只用于评审，不属于产品界面：

- **页面状态**：已结束、执行中、构建等待审批、部分完成、待接入·构建可用、待接入·只读阻断。
- **视图**：当前采集、任务历史、规则与构建、站点资料。
- **`chrome=0`**：隐藏原型控制区，便于按生产首屏截图；例如 `?state=done&view=current&chrome=0`。

主要状态和视图也会写入 hash 查询参数，便于直接分享某一屏。

## 覆盖的评审点

- 首屏先显示当前采集和结果；构建审批在摘要和视图之前。
- 页头只保留一个随状态变化的主操作；导出只在主操作或「更多」出现一次。
- 任务历史、规则与构建、站点资料各有入口，不再常驻右栏。
- 构建不可用或读取失败时，入口禁用并就地说明；只读阻断有独立文案。
- 候选规则证据不足时保留阻断理由和证据，不显示可直接激活的假按钮。
- 任务存在时，窄屏优先露出商品预览第一行；宽表在容器内滚动。

## 明确不做

- 不连接真实 API、SQLite、worker 或构建 harness。
- 不执行真实导出、暂停、取消、审批或规则激活；相关按钮只给 mock 反馈。
- 不代表最终视图名称、标签分组和 CSV／明细去向；这些在 `docs/39` 的待确认决策里。
- 不覆盖深色主题、读屏、真实触屏或完整四引擎浏览器矩阵。

## 文件

- `index.html`：外壳、侧栏、顶栏和挂载点。
- `styles.css`：沿用 v2 颜色令牌的静态样式与基础响应式。
- `app.js`：mock 数据、状态／视图切换、菜单、审批和键盘 tab 导航。
