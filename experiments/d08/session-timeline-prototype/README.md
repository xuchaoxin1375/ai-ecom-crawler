# 构建会话页原型（2026-11-26）

这是[构建会话时间线设计](../../../docs/46-构建会话时间线设计.md)的静态 HTML 草稿，用模拟数据比较 OpenCode 和 DeepSeek Harness 风格的会话页。它不是生产页面，不连接 FastAPI、SSE、SQLite、OpenCode 或真实构建。

> 生产范围已收窄：只替换构建详情现有的时间线组件。本原型的全高会话页、输入框、对话／轨迹标签和左侧列表只作视觉参考，不随本次实现迁移。

## 打开方式

在 `experiments/d08` 目录启动静态服务器：

```powershell
python -m http.server 8782
```

然后打开：

```text
http://127.0.0.1:8782/session-timeline-prototype/
```

不要直接用 `file://` 打开；ES modules 和相对样式会被浏览器拦截。

## 原型控制

页面顶部虚线区域只用于评审，不属于产品界面：

- **运行中**：思考流式追加、工具执行中、自动跟随。
- **等待审批**：审批卡片内联在时间线中；批准后工具转成功并追加验证结果，拒绝后追加拒绝通知。
- **已完成**：只读复盘，输入框禁用，思考折叠，主机验证通过通知。
- **追加事件**：模拟新的工具调用、文本和通知；用于验证跟随和折叠。
- **重置**：恢复运行中状态。

## 覆盖的评审点

- 独立全高会话页，不再挤在构建详情四视图内；顶部条只保留站点、构建、状态、模型、耗时和 token。
- 消息区占满剩余高度，输入区固定在底部，页面本身不滚动。
- 转录式紧凑行：思考、工具和活动组是 28px 行，助手文本是普通段落，用户消息是右对齐气泡；参考 OpenCode `timeline-next` 的行语法。
- 画布式全高布局、对话／轨迹标签、圆角输入卡和底部统计参考 DeepSeek Harness WebUI。
- 连续工具调用合并为活动组；历史组可折叠，当前组展开。
- 工具行摘要常驻，入参／输出按需展开；运行中显示 spinner，输出用深色 console 块。
- 思考流式展开，结束后可折叠；自动跟随和「回到最新」互不打断。
- 审批卡片内联在时间线中；批准／拒绝后的结果进入时间线。
- 状态行在转录末尾，显示当前活动或「工作耗时」；不在头部常驻。
- 底部输入框演示继续原会话；构建结束后只读。
- 1280 和 390 宽度下无页面级横向溢出；工具输出在自身容器内滚动。

## 明确不做

- 不连接真实 API、SSE、SQLite、构建 harness 或 OpenCode 会话。
- 不执行真实审批、暂停、继续、trace 下载或会话恢复；按钮只给 mock 反馈。
- 不覆盖完整 Markdown、文件 diff、子代理嵌套、搜索、虚拟滚动和跨构建对比。
- 不代表最终视觉令牌、深色主题、读屏或真实触屏验收。
- 不复制 OpenCode 的品牌、图标或产品文案；只参考时间线组织和活动块交互。

## 文件

- `index.html`：全高会话页外壳、顶部条、消息区和输入区。
- `styles.css`：复用站点原型令牌，补全高布局、活动组、工具行、内联审批和跟随按钮。
- `app.js`：模拟数据、场景切换、审批、折叠、自动跟随和继续会话。

生产实现建议、数据契约、接口和验收矩阵见[构建会话时间线设计](../../../docs/46-构建会话时间线设计.md)。
