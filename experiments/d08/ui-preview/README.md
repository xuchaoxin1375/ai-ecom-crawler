# D08 本地页面预览

## 目的与边界

用**真实案例**启动 D08 内部技术控制台的本地网页预览，供项目方检查页面用途、真实任务状态、计数、质量异常、导出和操作提示。页面本身标注“内部技术控制台／非业务工作台”，不包含批次导入、站点接入判断、构建会话或批次交付。

合成数据只用于布局草稿和截图检查，不能作为功能或业务验收。真实预览使用 `experiments/d03/familidoo` 的受管规则包，通过本地 API 创建并执行一个 6 商品任务，然后保持 `serve` 运行。

## 运行真实预览

在仓库根目录执行：

```powershell
app\.venv\Scripts\python.exe experiments/d08/ui-preview/run_real_preview.py --port 8775
```

脚本会：

- 创建临时账本和输出目录，启动 `ecom-crawler serve`（默认托管 worker，只绑定回环地址）。
- 用规则包 `familidoo-fr-d03@2026.11.21-1` 创建并启动一个 product 任务，最多 6 个商品／180 秒。
- 打印任务状态、计数、质量和 URL；任务结束后继续提供服务，`Ctrl+C` 停止。
- 打开 `http://127.0.0.1:8775/` 即可检查真实任务的列表、详情、商品预览、归档／导出和控制按钮。

## 只做布局检查

`serve_preview.py` 使用 `ui-1280/capture.py` 的合成数据，只用于页面结构和截图检查，必须标注为合成数据，不能替代真实案例验收。

```powershell
app\.venv\Scripts\python.exe experiments/d08/ui-preview/serve_preview.py --port 8776
```

## 2026-11-23 真实案例结果

- 计数：6／6 有效，0 失败、0 业务排除，0 条质量异常（品牌等可空字段缺失不再计入）；真实商品页和导出可用。
- 浏览器检查通过：页首用途说明、真实任务与计数、详情计数、质量异常、真实商品名、字段来源、归档／还原、导出 zip、新建真实任务、暂停、恢复、取消（二次确认）和不存在任务的“读取失败”提示。证据：`evidence.json`。
- 截图：`real-list-1280.png`、`real-items-1280.png`、`real-controls-1280.png`。
- 本轮真实数据暴露并修正了两个 mock 掩盖的问题：运行时原先把完整商品从 item 结果移走，真实页面拿不到正文状态和字段来源；现在保留紧凑的 `product_preview`，完整商品仍只写 `products.jsonl`。另外，品牌等可空字段缺失曾让每个商品都成为质量异常；现在只把正文非完整和非可选字段缺失计入 `quality_exceptions`，可空字段仍留在内部记录。两处都有真实 fixture 测试。

真实预览会发起目标站点请求；如果网络或站点不可用，页面会显示真实失败状态，不以合成数据代替。

## 2026-11-23 排队状态检查

- 现象：此前的合成预览用 `--no-worker` 启动，创建并启动的任务会停在 `QUEUED`；页面没有说明“外部 worker 模式”，看起来像状态故障。
- 修正：页首新增服务状态条，显示“托管 worker 运行中”或“外部 worker 模式：排队任务需要独立 worker 进程领取”；列表显示排队数量；任务详情在 `QUEUED` 时显示具体排队原因。
- 验证：`check_queue_state.py` 在 8776 合成只读预览上创建一个排队任务，确认外部 worker 模式、排队数量和详情原因均可见；截图 `queue-state-1280.png`。
- 真实预览 `run_real_preview.py` 使用托管 worker，排队任务会由 worker 领取；如果页面显示外部 worker 或未检测到 worker，按提示启动独立 worker。

## 限制

- 真实预览会访问公开站点并受网络、站点改版和访问预算影响；结果以当前任务账本为准。
- 页面只绑定回环地址；预览不保存整页原文、Cookie 或浏览器 profile。
- 真实案例通过不等于 A16 的业务验收；项目方仍需在 1280 实机确认页面和操作。
