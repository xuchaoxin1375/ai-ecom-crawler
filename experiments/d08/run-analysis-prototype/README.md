# 任务运行分析 Tab 原型

这是[任务运行分析 Tab 设计](../../../docs/59-任务运行分析Tab设计.md)的首版布局评审原型。它把「运行分析」放在任务详情现有的「数据明细 / 质量与验收 / 运行明细」之间，用来评审首屏信息层级、图表、失败构成和预算表达。

> 生产实现已在 2026-11-28 落地，并加入 `requests.ndjson`、请求/重试/错误响应/429 可选曲线和合图/分图；本原型仍只展示商品分析，保留作首版布局对照，不是生产 UI 的完整复刻。

## 打开方式

在 `experiments/d08` 目录启动静态服务器：

```powershell
python -m http.server 8790
```

打开：

```text
http://127.0.0.1:8790/run-analysis-prototype/?state=finished&view=analysis
```

不要直接用 `file://` 打开；ES modules 和相对资源会被浏览器拦截。ECharts 6.1.0 已放在 `vendor/`，不需要联网。

## 原型状态

顶部虚线评审条不属于产品界面：

- **已结束**：真实运行 `web-62d05ef69afc` 的分钟桶聚合；5,003 处理、4,924 有效、79 失败。
- **运行中**：截取运行中的一段，默认最近 15 分钟，展示冻结 / 回到实时、待采数和时长预算。
- **旧运行**：展示旧版本缺少 item 级原因时的说明；本原型不覆盖请求遥测，所以不会出现请求延迟图。
- **未开始**：排队任务的分析空态。

`chrome=0` 可隐藏评审条，便于按生产首屏截图。状态和视图会写入查询参数，方便分享某一屏。

## 覆盖的评审点

- 单次运行的产出、有效、失败曲线；速率 / 累计切换；图例、窗口、粒度和数据表。
- 失败构成、失败高峰、样例 URL 和“查看失败项”入口。
- 发现 → 候选 → 处理 → 有效 / 失败的漏斗，以及商品数、运行时长、网址数预算。
- 旧运行、未开始、运行中冻结和 390 窄屏。
- 图表使用语义令牌；Canvas 外图例；数据表作为可访问替代。

## 明确不做

- 不连接真实 API、SQLite、SSE 或 worker。
- 不在本原型中画请求曲线；生产实现的 `requests.ndjson`、请求/重试/错误响应/429 可选序列和合图/分图见[设计说明](../../../docs/59-任务运行分析Tab设计.md)。请求延迟仍是后续可选扩展。
- 不实现跨运行对比、站点长期趋势、AI 总结或 ETA。
- 不覆盖真实读屏、真实触屏和四引擎矩阵；这些在实现阶段按[任务运行分析 Tab 设计](../../../docs/59-任务运行分析Tab设计.md)验收。

## 数据说明

商品分钟桶由真实运行 `web-62d05ef69afc` 的 `events.ndjson` 聚合；失败原因和样例是原型展示用的合成值，不包含真实商品数据。生产实现中的请求遥测不在本原型范围。

## 文件

- `index.html`：外壳、顶栏、侧栏和挂载点。
- `styles.css`：当前项目令牌的静态复刻、布局和响应式。
- `data.js`：已结束、运行中、旧运行和未开始的 mock 状态。
- `app.js`：状态切换、Tab、图表、窗口、图例、数据表和空态。
- `vendor/echarts.min.js`：ECharts 6.1.0 本地构建，许可证见 `vendor/LICENSE`。
