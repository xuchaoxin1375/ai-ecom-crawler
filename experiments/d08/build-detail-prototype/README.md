# 构建详情与全局导航阶段 4 原型（2026-11-25）

这是[构建详情与全局导航改版设计](../../../docs/41-构建详情与全局导航改版设计.md)的静态 HTML 草稿，用于评审构建首屏、审批、继续／重新构建的区分、视图收纳和侧栏分组。它不是生产页面，没有接入后端。

## 打开方式

在 `experiments/d08` 目录启动静态服务器（需要同时加载同目录的站点原型样式）：

```powershell
python -m http.server 8782
```

然后打开：

```text
http://127.0.0.1:8782/build-detail-prototype/#/build?state=running&view=status
```

不要直接用 `file://` 打开；ES modules 和相对样式会被浏览器拦截。

## 原型控制

页面顶部的虚线区域只用于评审，不属于产品界面：

- **页面状态**：排队、运行中、等待审批、已暂停、失败、中断、成功、已取消、读取失败。
- **视图**：运行状态、验证证据、修复轮次、日志与 Trace。
- **`chrome=0`**：隐藏原型控制区，便于按生产首屏截图。

## 覆盖的评审点

- 侧栏按「采集工作台」和「规则与设置」分组，构建记录在规则与设置下；新建批次不再占全局快捷入口。
- 有待审批时请求固定在摘要之前；无待办时不渲染空审批模块。
- 继续原会话沿用同一 build／会话，重新构建跳转站点并产生新 build；两者文案和后果分开。
- 运行状态、验证证据、修复轮次和日志各自收纳；日志有界滚动。
- 排队、运行、暂停、失败、中断、成功、取消和读取失败分别有首屏状态。

## 明确不做

- 不连接真实 API、SQLite、构建 harness、SSE 或节点进程。
- 不执行真实继续、重新构建、取消、审批或 trace 下载；相关按钮只给 mock 反馈。
- 不代表最终视图名称、构建事实位置和侧栏分组；这些在 `docs/41` 的待确认决策里。
- 不覆盖 Rail 折叠、深色主题、读屏、真实触屏或完整四引擎浏览器矩阵。

## 文件

- `index.html`：外壳、分组侧栏、顶栏和挂载点。
- `styles.css`：导入站点原型的共享样式，并补构建详情专用块。
- `app.js`：mock 数据、状态／视图切换、审批、继续卡、菜单和键盘 tab 导航。
- 证据截图在仓库外 `workbench/build-detail-prototype-20261125/`。
