# 前端 v2（默认入口）

本目录是 v2 前端：React 19 + TypeScript + Vite + Tailwind CSS v4，覆盖应用外壳、批次列表、新建批次弹窗和批次详情。它已是默认入口：FastAPI 根路径 307 到 `/next/`，v2 构建挂载在 `/next/`；旧 Vue 仍在 `/batch/`，标注“已弃用”，只承接未迁移功能。

## 范围

- 桌面端：1280 主规格、1440 检查宽屏；768／390／320、移动抽屉和触屏适配后置。
- 已实现：应用外壳、服务状态、批次列表、筛选、指标条、状态徽标、站点就绪分段条、空／加载／错误状态；批次列表页内的“新建批次”弹窗（解析预览、保存草稿、保存并启动）；批次详情（工作票头、状态带、下一步、站点清单、启动弹窗（全量采集、复跑已完成／已取消站点）、暂停、归档／恢复、取消确认和 ZIP 导出入口）。全量采集不额外设服务层商品数或时长上限，保留重试次数、进程／适配器安全超时和 sample 存档 20 页。
- 未实现：继续导入站点、站点详情、任务列表／详情、SSE、构建面板；这些操作当前跳转旧版 `/batch/`。导出 ZIP 的下载内容尚未核对。
- 链接策略：批次行“查看”进入 v2 批次详情；详情里的站点链接和“在旧版中继续导入或查看站点”进入旧版；新建批次在 v2 弹窗完成，不跳页；保存或启动后留在列表并刷新数据。

## 启动

```powershell
cd app/frontend-v2
npm install
npm run dev
```

前端地址是 `http://127.0.0.1:5175/next/#/batches`，批次详情按 `http://127.0.0.1:5175/next/#/batches/<batch_id>` 访问，新建批次弹窗可用 `http://127.0.0.1:5175/next/#/batches?new=1` 直接打开。FastAPI 启动后根路径 `http://127.0.0.1:8775/` 会跳到 `/next/`；旧版在 `/batch/`。Vite 把 `/api`、`/batch` 和 `/legacy` 代理到 `http://127.0.0.1:8775`；写请求会按后端要求把代理后的 `Host`／`Origin` 对齐到 API 源，需要另开一个 shell 启动本地服务：

```powershell
app\.venv\Scripts\python.exe -m ecom_crawler serve `
  --db /path/to/tasks.db --out-root /path/to/tasks `
  --rules-dir /path/to/rules --host 127.0.0.1 --port 8775
```

如果服务端口不同，修改 `vite.config.ts` 的代理目标。
