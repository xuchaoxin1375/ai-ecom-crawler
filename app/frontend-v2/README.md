# 前端 v2（默认入口）

本目录是 v2 前端：React 19 + TypeScript + Vite + Tailwind CSS v4，覆盖应用外壳、批次列表、新建批次弹窗、批次详情、继续导入、站点详情、站点级构建、任务列表、任务详情和结果验收反馈；批次列表与站点清单提供行末操作菜单和勾选批量操作。它已是默认入口：FastAPI 根路径 307 到 `/next/`，v2 构建挂载在 `/next/`。v2 导航不再提供旧版工作台、旧版任务列表或技术兜底入口；旧 Vue 构建仍由后端在 `/batch/` 托管，只作任务 SSE、站点任务历史等未迁移功能的直访兜底，不进入 v2 界面。

## 范围

- 桌面端：1280 主规格、1440 检查宽屏；768／390／320、移动抽屉和触屏适配后置。
- 已实现：应用外壳、服务状态、批次列表、筛选、指标条、状态徽标、站点就绪分段条、空／加载／错误状态；侧栏支持 248／64 折叠、pinned 本地偏好、悬停与键盘聚焦 peek、Esc 收起并回焦，主内容宽度只随固定状态切换；单分组不画 Rail 分隔线，顶栏品牌槽跟随侧栏 slot，面包屑只在详情页显示，右侧状态与内容右边缘对齐；菜单、批量条、Toast、提示条和对话框有克制的进出场反馈并尊重 reduced-motion。批次列表页内的“新建批次”弹窗（解析预览、保存草稿、保存并启动）；批次详情（工作票头、状态带、下一步、站点清单、启动弹窗（全量采集、复跑已完成／已取消站点）、继续导入弹窗、暂停、归档／恢复、取消确认和 ZIP 导出入口）；站点详情（工作票头、任务／覆盖／质量指标条、当前任务控制、结果预览与大图弹窗、质量异常、CSV 预览、任务明细、构建面板与构建／修复弹窗、站点事实、导出和技术详情）；任务列表（状态／类型／批次／站点／归档筛选、结果列、概览、分页和行操作）；任务详情（工作票头、指标条、任务控制、归档／恢复、导出、结果预览、质量异常、CSV、商品／网址分页、任务事实、内容完整度和结果验收反馈）。批次列表和站点清单支持行末操作菜单与勾选批量：批次可查看、复制 ID、启动、暂停、继续已暂停任务、导出、归档／恢复，并支持批量暂停／归档／恢复；站点可查看、启动／复跑、暂停／继续／取消任务、导出站点 ZIP，并支持批量启动／任务控制。取消类操作二次确认，批量操作显示受理／跳过／失败。构建时间线通过 `/api/builds/{id}/events` SSE 实时追加，思考块默认展开，工具调用显示状态和入参／输出，新内容自动跟随；实时思考需服务端 `ECOM_BUILD_CAPTURE_REASONING=1`，默认不写入 trace（`ECOM_BUILD_PERSIST_REASONING=0`）。构建启动前 host 机会式探测 robots.txt，只把 `Sitemap:` URL 注入 brief，失败不阻塞，不读整份、不按 disallow 拦截；构建 workspace 写入 `work/AGENTS.md`，固定 brief／参考规则的阅读顺序和“不要读 robots 全文”的规则。全量采集不额外设服务层商品数或时长上限，保留重试次数、进程／适配器安全超时和 sample 存档 20 页。
- 未实现：任务 SSE、站点任务历史、任务手动创建表单和活动真实任务的暂停／继续／取消验收；任务详情使用轮询，任务由批次或站点启动。导出 ZIP 的下载内容尚未核对。
- 链接策略：批次行点击名称或菜单“查看批次”进入 v2 批次详情；批次详情的站点行进入 v2 站点详情，任务列可进入 v2 任务详情；站点详情可打开当前任务详情；任务详情可回批次、站点和全部任务。新建批次、继续导入、站点采集启动、构建启动／修复、取消确认、任务归档和反馈分诊都在 v2 页面或弹窗完成，不跳旧版；保存、启动、导入或构建后留在当前页并刷新数据。行菜单操作在列表内就地完成，批量操作使用列表内的结果提示或右上角通知。

## 启动

```powershell
cd app/frontend-v2
npm install
npm run dev
```

前端地址是 `http://127.0.0.1:5175/next/#/batches`，批次详情按 `http://127.0.0.1:5175/next/#/batches/<batch_id>` 访问，站点详情按 `http://127.0.0.1:5175/next/#/batches/<batch_id>/sites/<site_key>` 访问，任务列表和详情按 `http://127.0.0.1:5175/next/#/tasks`、`/next/#/tasks/<task_id>` 访问，新建批次弹窗可用 `http://127.0.0.1:5175/next/#/batches?new=1` 直接打开。FastAPI 启动后根路径 `http://127.0.0.1:8775/` 会跳到 `/next/`；v2 不再提供旧版入口。Vite 仍把 `/api`、`/batch` 和 `/legacy` 代理到 `http://127.0.0.1:8775`，其中 `/batch`、`/legacy` 只用于直接访问旧构建兜底；写请求会按后端要求把代理后的 `Host`／`Origin` 对齐到 API 源，需要另开一个 shell 启动本地服务：

```powershell
app\.venv\Scripts\python.exe -m ecom_crawler serve `
  --db /path/to/tasks.db --out-root /path/to/tasks `
  --rules-dir /path/to/rules --host 127.0.0.1 --port 8775
```

如果服务端口不同，修改 `vite.config.ts` 的代理目标。要在构建时间线里看到实时思考，启动服务前设置 `ECOM_BUILD_CAPTURE_REASONING=1`；需要把思考写入 trace 时再设 `ECOM_BUILD_PERSIST_REASONING=1`，默认不写。
