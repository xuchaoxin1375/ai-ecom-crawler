# 前端

本目录是唯一前端：React 19 + TypeScript + Vite + Tailwind CSS v4，覆盖应用外壳、任务工作台（任务树、最近任务、运行信息、新建批次和添加已有批次动作）、任务列表、任务详情、结果验收反馈、构建记录列表／详情、模型配置和系统设置。批次只作为批量创建任务的入口，批次列表、批次详情和站点详情页面已退役；站点级构建启动／修复入口暂未迁入。FastAPI 根路径直接返回本目录的构建产物 `dist/index.html`，静态资源挂在 `/assets/`；旧 `/next/` 仅保留兼容重定向。

## 范围

- 桌面端：1280 主规格、1440 检查宽屏；窄屏已适配到 768／390／320，使用顶部菜单和移动抽屉，待项目方验收。触屏目标在移动端提升到 40–44px。
- 已实现：应用外壳、服务状态、任务工作台（任务树、最近任务、运行信息、新建/添加批次动作、目标目录）、任务列表（状态／类型／站点／归档筛选）、任务详情（结果、质量、CSV、反馈、SSE）、构建记录列表／详情、模型配置和系统设置；任务树支持拖拽排序，目录和运行信息可收起。批次列表、批次详情、站点详情和站点级构建入口已退役；批次只保留新建/添加动作。
- 未实现：任务手动创建表单和活动真实任务上的暂停／继续／取消验收；任务工作台的列设置、运行历史树、批量移动和快捷键未实现；任务详情已订阅 SSE 并在断线时回退轮询，任务由批次或站点启动。批次和任务导出 ZIP 的清单与站点文件已在 2026-11-24 的 P1 复验中核对，仍缺真实设备首屏用时、线上网络延迟和跨浏览器复验。
- 链接策略：任务工作台的任务节点进入最近运行或任务详情；任务列表进入任务详情；任务详情可回任务列表。批次只在新建／添加弹窗中出现，不再有批次／站点详情页面。

## 启动

```powershell
cd app/frontend
npm install
npm run dev
```

前端地址是 `http://127.0.0.1:5175/#/workbench`，任务列表和详情按 `http://127.0.0.1:5175/#/tasks`、`/#/tasks/<task_id>` 访问，构建记录和详情按 `http://127.0.0.1:5175/#/builds`、`/#/builds/<build_id>` 访问。批次通过工作台的“新建批次／添加已有批次”弹窗创建或导入，并选择目标目录。FastAPI 根路径 `http://127.0.0.1:8765/` 直接返回前端构建。Vite 把 `/api` 代理到 `http://127.0.0.1:8765`；写请求会按后端要求把代理后的 `Host`／`Origin` 对齐到 API 源。组件改动由 HMR 立即生效，不需要重启后端；需要对着临时实例开发时用 `ECOM_API_TARGET` 覆盖代理目标：

```powershell
$env:ECOM_API_TARGET = "http://127.0.0.1:8899"
npm run dev
```

先按 `app/README.md` 的“开发实例与前端热更新”启动 8765（推荐 `python scripts/serve_dev.py start ...` 或 `restart`）：

```powershell
python scripts/serve_dev.py start `
  --db /path/to/tasks.db --out-root /path/to/tasks `
  --rules-dir /path/to/rules
```

如果服务端口不同，用 `ECOM_API_TARGET` 指定，不要改默认入口。要在构建时间线里看到实时思考，启动服务前设置 `ECOM_BUILD_CAPTURE_REASONING=1`；需要把思考写入 trace 时再设 `ECOM_BUILD_PERSIST_REASONING=1`，默认不写。

## 校验

```powershell
cd app/frontend
npm run lint
npm run typecheck
npm test
npm run build
npm run format:check
```

`npm test` 是日常快速回归，不启动真实浏览器。改动批次、任务或导出接线时，再按[前端测试策略](../../docs/23-测试策略.md#前端测试怎么跑)运行独立 Chromium 冒烟。该入口验证 FastAPI 托管的构建产物和实际下载内容，不使用开发服务器或正式账本。
