# 生产应用（app/）

本目录是 monorepo 中生产应用的承载位置。当前只有边界说明，尚未开始实现。

## 边界

- `docs/` 是业务口径与验收的唯一入口；`app/` 不复制业务规则。
- `experiments/` 是实验与原型，不作为生产代码；可复用的契约结论先回写 `docs/` 或 ADR，再进入 `app/`。
- `app/` 不进入 `scripts/export_docs.py` 的文档包；文档导出仍只包含 `docs/`。
- 生产代码最终闭源；第三方依赖保留各自许可证。

## 开工条件

G0 立项门已于 2026-11-20 有条件通过，见 [`docs/24-G0结项记录.md`](../docs/24-G0结项记录.md)。实现前仍需按该记录完成 D01 补测、确定 `app/` 的最小布局和依赖，并按 [`docs/21-开工前检查清单.md`](../docs/21-开工前检查清单.md) 继续跟踪契约门和交付门。当前不在这里写站点专用代码或临时脚本。
